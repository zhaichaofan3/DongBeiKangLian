# 双人渡河与密林入村

本轮按用户要求完成S10追加：沈砚与陆山登船、坐稳后顺流漂行，姜岚在对岸接应；上岸后沿不同颜色的土路穿过密林，到原村口由短剧情引入原三段战斗。源码与独立试玩包的运行、渲染及完整路线验证均已完成，试玩候选版仍标记为0.7.0-rc1，本批修订为20261016-river-journey。

## 实现

- 38秒过河演出，分为登船、林岸远景、船上近景、靠岸与下船。使用用户原木船、栈桥、河道及现有我军蒙皮人物，字幕5条，暂未配音。
- 新渡口位于原村庄以南约150米。土路宽约5.3米，沿折弯通往原村口；2017棵既有松树实例与真实树干碰撞、土石坡和倒木形成路外密林。落脚、树干与地表使用真实碰撞，导航通往原村口。
- 村口姜岚说明名册上乡亲尚未撤离、日军正在搜村，随后才开放首段战斗。陆山留岸边保管名册，姜岚沿路跟随并继续提供村内火力支援。
- Esc暂停演出，Enter及暂停菜单略过；返回菜单清理演出人物与音频。过河中保存使用登船前安全点，上岸与林中分别记档。旧村庄存档接续原阶段，物资不会因重复完成演出而增加。
- 保留村内22组原院落、两道任务门、三段12名敌人、用户音频、开场旁白和第一人称手部；未改写原始素材。

## 检查与修正

第一轮专项因两处测试类型推导失败未运行，日志保留于source-initial。修正后实走发现地面三角朝向反转，人物陷入地表；后续修正地表碰撞，并翻正土路。渲染复查又发现登船地点落在原河道弯曲岸坡、下船镜头被树遮挡，已经调整船与水道位置、栈桥站位、林岸开口和镜头。早期通过数不计作最终验收。

source-render-1为首轮52项运行通过，仍有画面问题；source-render-2包含岸边空地边界检查失败，未计为通过。source-render-3的52项通过用于中间验证，后续专项另增加实际水面几何检查。登船前保存、暂停恢复、略过、菜单清理、上岸和林中磁盘读档、旧村庄档、村口剧情一次性、沿路真实移动及6处林内冲刺跳跃均纳入最终检查。

旧smoke与linear_route使用约3秒过河等待，现改为跟随演出时长；完整combat_route播放完整过河并实际走过新林道，不以传送替代。测试始终串行，使用独立QA存档。

首轮完整战斗虽然到达胜利，但登船时访问了已经释放的旧敌人节点，运行日志仍有脚本错误，因此不计为通过。已补有效性检查，并关闭演出节点的物理插值以避免镜头提示；后续完整通关无此错误。追加反向栈桥实走发现平台台阶卡脚，已补岸边踏板和平台铺板；失败现场在source-ferry-pier-failure。落水回岸保护与真实反向通行纳入新增检查。

音频回归的暂停项曾失败，等待导航准备后仍未解决。状态记录确认敌人枪声和环境声已暂停，而玩家枪声在暂停前已结束。将脚步流准备移到短枪声之前，再确认两路枪声都在播放后暂停，28项检查通过；没有修改用户音频或运行时混音逻辑。三次失败／诊断分别保存在source-audio-pause-timing-failure、source-audio-pause-second-failure和source-audio-pause-diagnostic。

最终船体水线下调至-1.7米，岸边与演出船匹配；村口谈话人物改为面向玩家。source-regression-final包含29组1145项通过，完整37敌、生命100通关；source-render-final为60项与11张1280×720画面，已复查登船、船上、下船、森林和村口。

发布首轮完整路线达到37敌胜利、存档有效，但姜岚开火数为0，最终参战检查失败。补充逐条件诊断后确认其余条件全部满足；自动玩家即时清敌，短暂3秒停止射击仍不足以让速度较慢的战友跟上。测试保留实际战斗和视线，在首次看见村庄敌人后最多15秒暂缓自动开火，让战友跟上并获得射击机会；源码、独立发布及发布有画面完整路线随后均通过。仅调整测试控制器，没有修改战友运行时伤害、视线或移动规则，也没有取消参战要求。失败日志与完整状态在release-combat-diagnostic；未删除或计入最终通过数。
