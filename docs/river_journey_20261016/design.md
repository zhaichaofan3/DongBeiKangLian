# 双人渡河与密林入村

用户要求：第一关结尾两人登船、过河并沿河漂行；上岸为大片树林，脚下有明显不同颜色的引导道路，非道路区域树木茂密；沿路抵达村口，以短剧情引入。

本轮按 S10 追加制作，保留现有剧情、第一人称手部、用户录音、村内原模型和三段战斗。乘船者为玩家沈砚与获救的陆山，姜岚沿原故事绕山路到对岸接应。新增台词先使用字幕，不替换或拼接用户现有配音。

## 制作安排

1. 用原木船、栈桥、河道和人物制作38秒过渡：双人依次上船、坐稳、顺流经过林岸、靠岸、依次下船。
2. 将对岸渡口延后到村南密林，浅色土路连接原村口。村庄内部、敌人数和院门次序保留。
3. 非道路区通过密集松林、坡脚岩石、倒木和陡林坡组织边界。地面和道路使用已有贴图，色相与明度均有区分。
4. 林中自动保存进度；村口触发姜岚短对话，之后才激活原村庄战斗。
5. 支持暂停、继续、略过过河、返回菜单和磁盘恢复；过河中断从登船前安全检查点重播，上岸后保存独立检查点。旧村庄存档继续原战斗，不强制重走树林。

## 验收范围

检查船和两个人物随时间移动、上船/坐姿/下船姿态、镜头非空与画面构图；分别检查暂停和跳过、上岸存档、林中读档、旧村庄档、入村剧情只触发一次、道路真实移动、非道路冲刺跳跃边界、村内院门和实际战斗通关。源码与独立发布分别验证，历史通过数不作本轮结果。
