# 人物头部与手部修正接续验收

本轮接续用户因网络中断未完成的人物优化，归入 S19；不推进 S32 的其他制作。上轮诊断与原始失败记录保留在 `../user-model-fix-20261015/`。

## 已接续的修正

- 陆山取消遮住眼睛的旧额头绷带，保留腿部包扎、未治疗与治疗后的伤势动作。
- 我军保留用户人物自带的手套几何与贴图，以及放松和握枪两套手形；玩家第一人称手臂与武器文件受原始哈希保护。
- 本轮复看近景发现上轮握枪手形还会将手指抬到枪身上方。原算法沿世界高度压缩手指，却保留两只原始手掌不同的朝向；现在分别按掌面局部方向弯曲，并保留手指厚度、手腕和袖口连接。
- 增加低位持枪及瞄准时左右手近景，并检查实际变形手套表面到枪握点的范围；原有虚拟掌心握点检查继续保留。
- 全关卡复测发现上轮将角色准备接口增加手形参数后，开场仍残留旧的两参数调用，导致开场人物创建中断。开场现在沿用 `Human.build()` 中已经完成的阵营及握枪手选择，移除重复初始化；A10 背枪行走的放松手切换继续保留。

## 失败记录与修复

模型已重新生成并导入。第一次新增网格距离检查混用了枪的父节点坐标和人物坐标，造成约 1 米的误差；该检查已统一坐标，初次失败日志保留为 `character-first-failed.log`。实际近景复看确认上方伸出的手指已收回，人物无窗口专项 59/59 通过。首次完整回归在开场旧接口处失败，保留 `source-regression-first-failed.log` 与 `opening-initial-failed.log`；修复后将重新运行全套，不沿用之前的通过数。

## 最终验收

源码与独立发布包完整回归分别 **22 组、682 项**通过，均完成 19 名敌人自动通关；两端额外人物实际渲染各 **83/83** 通过、各 24 张截图。源码及发布包在 1280×720 与 960×540 的实际画面专项各 **46/46** 通过，包括真实全屏音量拖动。已复看两端的陆山正侧面、治疗姿态、我军双手与持枪近景，以及电报房行走和救援对话。玩家 7 个受保护文件哈希一致。

发布测试从工程目录外启动，使用发布包中的游戏资源。源码及发布端完整日志分别是 `source-regression.log`、`release-regression.log`；人物证据在 `source-characters/` 与 `release-characters/`，四组画面专项在 `*-render-1280/`、`*-render-960/`。开发目录另保留 `source-gameplay/`、`release-gameplay/` 和两端的 `*-opening-checks/`，防止后续统一测试覆盖本轮证据。
