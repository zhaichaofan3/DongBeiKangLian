# 村庄窄街与院落巷战修订

版本：0.7.1-rc1。日期：2026-10-16。状态：独立包回归进行中，最终结果尚未确认。

## 最终布局与操作

使用用户原“东北农村”大型院落，以原比例相向拼接12组，六段街面实测墙间距均为3.63米。三处木料封街引导玩家转入西院、东侧夹巷和北院；两道实体任务门按清敌阶段开放，保留首关剧情和村庄三段战斗。实墙遮挡后续敌人，0.8米低网只封支路。

`village_passages.glb`从原`village_4.blend`派生，局部开两处2.5米侧门；原模型与制作源保留。消除院门台阶，导航按同步后的实际碰撞生成。村内铺灰褐土路，补树、露岩、柴垛、劈柴工具与水桶，村外林带避开林场作业空地。

C切换蹲伏，Ctrl按住蹲伏，Q/E按住左右探头。探头最大0.4米/11度，头部碰撞限制伸出和回正，冲刺、暂停时收回；低顶下不能站起。敌人按实际露出的头部判断视线。为避免冲突，互动改F，包扎改H，提示和说明已同步。

村庄存档独立升级为4，旧村庄档回到同一阶段安全入口，保留击杀和弹药；林中档保留玩家与陆山岸边位置。首关地图版本仍为5，避免重复迁移首关坐标。

同批完成电报房实体外墙、渡口可见水面、顺流避码头航线与电报机特写。历史开场仍为68.18秒，任务段80.1秒，完整用户旁白不变，共28镜。开场村庄取景收紧，并保留村边伐木作业点。
