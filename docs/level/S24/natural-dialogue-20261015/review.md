# 交谈衣服与动作修订

用户反馈开场衣服粘连、人物动作别扭。排查确认旧衣身与袖子体素合并后形成腋下到腰部的连面，内侧袖子还被分配了躯干权重；旧讲话循环持续抬起同一条前臂，又叠加按台词制作的动作。

本轮将衣身与两只袖子分别生成、分别蒙皮，仅在肩帽处重叠衔接；袖子内侧不再跟随胸腰，肘部用平滑权重过渡。共享模型保留13根身体骨骼、守卫握枪手、红圈与胡须、灰色友军衣服和既有材质来源。角色全变体三角面总数为72,128。

交谈段使用低位放松姿势，每句只安排一次柔和的准备、抬手与收回；说话者轻微转头，听话者延迟点头，视线朝向对方，停顿时保留两人站立。删除了交谈中的通用重复摆臂和额外随机扭头。台词、音频、字幕时码、正式镜头及任务交接没有调整。

弯臂检查：同一肩部0.35、肘部0.9弧度姿势下，旧模型338个抽样袖子顶点含胸腰权重，新模型为0；衣服边缘拉伸95分位从2.706倍降至1.201倍，最大值从7.963倍降至1.611倍。前后模型顶点数量不同，数据说明同一空间筛选和姿态下的变形范围，并非逐顶点对比。

全段60帧采样共8,638个人物姿态，手臂单帧最大变化约0.0216弧度，手掌单帧最大位移约9.46毫米；手掌与衣身保持间隔，未见突然抬臂或甩手。扶人镜头保持既有15厘米接触容差，没有将该镜头或S32整体标为最终美术完成。

`source-render-*` 和 `release-render-*` 保存正式镜头及衣服近景；`07-coat-three-quarter` 是仅供验收的机位，未接入正式开场。最终源码、发布及渲染验收见 `final-validation.json`。仍需用户真人观看连续表演及听审，自动采样不代替主观观感。

保留的首轮 `source-headless/validation.json` 中，新增测试曾误用3.5厘米扶人接触阈值，导致该断言失败；原有实现及原S32检查一直采用15厘米容差，本轮没有改变扶人动作。测试已恢复原约束，之后完整回归与渲染均另留最终记录。`source-regression.log` 是补充远距离接近条件之前的中间回归；本轮最终回归以 `source-regression-final.log` 为准。
