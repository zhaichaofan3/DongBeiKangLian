# S35 实际场景性能验收（补测后的当前结论）

日期：2026-10-15。Godot 4.7.2 / GL Compatibility；RTX 5060 Laptop GPU；1920×1080、balanced、100%3D、VSync关、不限帧。

## 有效测量

场景按实际 `_process` 时钟播放，预热1秒再连续采样，核对墙钟、演出时钟、窗口及渲染尺寸；图片读回在计时之外。

交火保留正常生命、武器间隔、弹夹和装填；玩家15发、守卫10发。五名守卫重新排列在生产场景测试位置，关闭线性路线门禁，仅用于稳定触发真实AI视线／开火代码，不代表正常关卡难度。玩家每700ms朝守卫旁射击。

固定视角复测 `s35-20261015-balanced-1920x1080.json`：森林／木场／办公室P99为7.41／5.39／4.68ms，S01对应8.62／7.07／5.63ms。实际通关路线 `s35-20261015-combat-source-1920x1080.json` 活动P99为6.972ms、9敌通关；玩家9发、敌人0发，不能用它代表持续双方交火。

## 判断与限制

现有镜头分层可见性和有上限的枪火／爆炸池已控制开销。以上P99均低于60帧的16.67ms预算，未发现有证据支持进一步降低画质的必要；本步没有新增猜测性的LOD或粒子削减。交火最大22.314ms仍有偶发尖峰，不能称每帧都达标。

早期120帧、固定步长开场样本仅作探索；独立进程的差异不能证明着色器暖机原因。旧JSON及历史检查点保留，原“正式完成／冷启动原因确定”结论撤回，以本报告为准。

本报告只说明本机短期场景测量。低配机器、长时间热降频、真人操作和听感未验收。S28/S29未听审和S30最终混音仍保留。下一步S36：源码／发布包回归、候选包和已知限制归档。
