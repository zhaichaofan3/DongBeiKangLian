# S26 枪口火焰与烟气验收

日期：2026-10-15。当前源工程的两把第一人称武器与实际守卫开火入口已接入。

## 实际成果

- 共享 MuzzleEffect 提供渐透明的交叉火焰、正向软星形枪火、薄烟和无阴影短光。深度测试保持开启，墙后枪火不会透墙显示。
- 第一人称每次合法开火立即更新当前枪口位置；光闪 0.045 秒，6 颗薄烟粒子 0.38 秒内消散，0.46 秒隐藏整层。烟气在世界坐标模拟，不随玩家转头整体拖动。
- 守卫枪火从当前动画步枪的真实枪口发出，短闪 0.065 秒，7 颗烟气粒子，0.46 秒回收。最多保留 8 组，超限移除最旧组。
- 切枪、读档、暂停清理瞬态效果，继续游戏不会重播旧闪光；空弹和换弹不会触发效果。原有伤害、弹药、动作和音效入口继续使用。

## 性能实测

1280×720、balanced、GL Compatibility、RTX 5060 Laptop GPU，关闭垂直同步和帧率上限。固定镜头，每组预热 1 秒、测量 3 秒；开火组每 0.24 秒发出六处远枪火和一发实际手枪。包含烟、短光、弹道线、声音和后坐力，不单独隔离 GPU 特效成本。

| 条件 | 无开火均值 | 密集开火均值 | 无开火 P95 | 密集开火 P95 |
|---|---:|---:|---:|---:|
| 日间 | 3.501 ms | 3.380 ms | 4.756 ms | 4.446 ms |
| 暗场 | 3.064 ms | 3.309 ms | 3.895 ms | 4.787 ms |

日间的小幅反向变化视作短样本噪声，不能据此宣称性能提升。暗场平均增加约 0.245 ms。完整数据见 performance-v2.json；这不代表低配机器或完整关卡性能承诺。第一次性能脚本访问已释放实例，performance-v1 的 PASS 不被采用，失败日志和原因完整保留。
