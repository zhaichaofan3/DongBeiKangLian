# S17 持枪姿态与前臂修订

2026-10-15。用户指出上一版前臂在托枪手处出现明显的 90° 折弯，并要求继续按参考图校准大小与位置。本轮只调整第一人称枪械组合的构图、托枪手腕方向和袖筒连接，保留枪身、握点、手指机构与换弹逻辑。

## 本轮改动

- 托枪手腕改为向上、向前的斜向姿态，并将手掌朝向枪托；袖筒沿腕部继续向画面下方延伸，去掉横向手腕接垂直袖筒的直角外观。
- 托枪手的手、袖口、袖筒和细节采用同一比例调整，避免只放大手掌或只拉长袖子造成断层。
- 步枪待机位置保持在参考构图附近：枪口归一化位置约 `(0.563, 0.615)`；枪机和托枪手仍位于画面右下区域。驳壳枪保持原独立姿态。
- 开场、普通游戏、瞄准、读档恢复仍共用同一套持枪构图；没有改变枪身几何、武器功能或第一人称视角逻辑。
