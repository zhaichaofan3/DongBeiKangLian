# S17 持枪移动、瞄准、开火、装填与受扰恢复验收

日期：2026-10-14；基线：0.6.1。

## 实际改动

`fps_player.gd` 在切换武器时立即重置上一把武器的弹夹可见性、枪机位置／旋转和左右手姿态，避免中断装填后旧武器残留中间状态。恢复存档时同时清空水平速度和脚步相位，避免恢复后带着旧的移动节奏继续播放。

## 专项验证

`s17_weapon_motion.gd` 用真实第一人称玩家完成 **10/10**：

- 持枪移动中进入瞄准，速度、FOV、准星居中和有界晃动通过。
- 移动瞄准中开火，弹药、闪光和后坐力均正确。
- 枪机和后坐力在射击后恢复；装填中弹夹可见。
- 切换到手枪立即中断步枪装填并隐藏／复位旧武器状态。
- 受击扰动出现并自然衰减；恢复存档清空移动和武器扰动状态。

证据：[`weapon_motion.json`](weapon_motion.json)、[`weapon-motion-runtime-final.log`](weapon-motion-runtime-final.log)。
