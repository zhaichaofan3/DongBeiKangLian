# 电报房直线刺刀冲锋修订

用户反馈最后一名守卫冲锋时会拐弯。本轮移除刺刀演出中的网格寻路和沿途改朝向，转身结束后沿起点与肉搏落点之间的直线前进，朝向始终固定。

发动前用角色胶囊体检查整条通路；桌椅或墙体遮挡时，末敌先按正常移动接近，通路打开后才转身、喊叫并直线冲锋。没有移动家具或取消碰撞。第二道门原有突袭、叫喊音频、空格肉搏、失败重试及旧存档流程保持。

源码已通过四名末敌分别触发的共线、固定朝向、单向前进、到达肉搏检查，每人采样25点；另检查桌子和墙体阻挡，以及绕过桌子后的发动条件。

补测发现：普通射击停距为17米，而冲锋发动距离为14米，末敌可能停在两者之间；粗网格也可能让畅通区域的接近过程绕路。本轮使末敌在射程外继续接近，并在胶囊体确认无阻挡时直接沿玩家方向靠近，有遮挡时才用正常寻路。对应的首轮失败回归保存在 `source-regression-range-failure.log`（位于S24同轮证据目录），最终复测另存。

本轮最终源码、发布包、两种分辨率的记录由 `final-validation.json` 和关联日志给出。早期 `source/validation.json` 仅是首轮21项检查，不能代表之后所有复测。真人操作难度尚未重新验收。
