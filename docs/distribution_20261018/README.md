所有游戏运行串行执行，使用QA存档；临时解压和安装位置均在工程外的独立中文/空格路径，实际运行交付EXE，无需本机Godot执行文件。最终结果见`verification.json`。

2. 便携EXE从独立工作目录自动找到自身PCK，基础任务/输入/战斗/存读档108/108，退出码0。
3. 静默安装至中文路径；日志确认当前用户安装、64位、无需重启；核对全部载荷文件、Windows卸载登记、游戏/说明/卸载三个开始菜单入口。

5. 实际卸载，确认载荷文件、卸载登记和开始菜单目录清除，真实玩家检查点和设置的存在性及SHA-256不变。

- `attempt1-*`：安装及文件核对成功，检查脚本错误地按`/GROUP`测试名寻找快捷方式。关闭选择程序组页面的当前安装器实际使用产品中文名称；修正检查脚本，安装器未修改。失败后已卸载。
