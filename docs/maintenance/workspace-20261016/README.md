## 分类规则

根 [README](../../../README.md) 负责试玩、编辑和目录导航；[文档索引](../../README.md) 汇总当前与历史证据；[文件指南](../../FILE_GUIDE.md) 列出具体路径；[素材库索引](../../../AssetLibrary/README.md) 区分原始、可编辑和游戏版本。

本批使用 [workspace_maintenance.py](../../../tools/workspace_maintenance.py) 生成清单、逐项核验后操作，并以日志防止覆盖重跑。文件复制到归档且验证一致后才移除原位置；派生自动保存副本在删除前后均核对完整检查点内保留文件。可重建缓存按限定路径清理。

本轮验证范围是目录整理与文件完整性，没有重新执行游戏战斗回归。首关制作验收保持 [原记录](../../first_level_rebuild_20261016/review.md) 的日期与范围。最近完整游戏快照为 `WorkBackups/20261016-125835-S10-done-086d8b/`；本轮整理的最新检查点查 [PROGRESS.md](../../../PROGRESS.md)，恢复时还需按移动清单还原目录去向。
