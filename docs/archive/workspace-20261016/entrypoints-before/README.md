# 东北抗联-烽火回声

东北抗联题材原创单机第一人称游戏。1938年深秋，虚构地点“青岚林场”：穿过检查口和木料巷，进入电报房取回名册、切断中继、救出陆山，再护送至渡口，过河后与姜岚肃清松岭屯。

当前为 **0.7.0-rc1 本地制作候选版**，使用Godot 4.7.2、GDScript和GL Compatibility。可离线运行，人物、配音和整体观感仍在完善。本页说明当前工程，历次制作结论保存在各自的历史记录中。

## 当前内容

- 首关已重构为304米纵深的线性林场山谷，前两道关口间隔76米；两段折弯林道、实体土坡和实墙隐藏下一场战斗，目标提示沿道路拐点引导。原剧情保留，旧紧凑地图存档迁移到新路线。
- 沿途增加林工棚屋、木料堆、劈柴点、手工工具、水桶和编筐，林缘以岩石、近树、蕨草和外围山脊填补空地。按1938年东北林场的生产生活组织布置，主路和战斗区留出通行空间；所有林场棚屋统一使用已去英文广告的贴图。
- 开始界面使用林场实景，可观看两段开场，也可直接进入林场。
- 历史序章使用用户提供的完整录音，含自带配乐与17条字幕；任务序幕通过沈砚、姜岚的谈话和行军进入任务。两段共27镜，约148秒，含接管淡出。
- 任务序幕播放用户新提供的姜岚8句录音；其余没有录音的对白保留字幕、暂不发音。历史旁白、音乐、音效和日军叫喊继续保留。
- 艺术化长白山天池有环形山体、湖水、山坡树林、岩台及下山路线。场景为叙事创作，不是实地1:1复刻。
- 我军使用用户提供的冬装人物，军服改为灰色、军帽加红星；日军使用用户提供的军帽人物，保留红圈与八字胡标识。林工保持平民造型，玩家第一人称手臂保留；步枪换为用户98k，枪栓和弹夹继续独立运动。
- 对话时玩家采用枪口朝下的低位持枪，结束后恢复战斗姿势。普通握枪、瞄准、拉栓和换弹沿用原有手部模型。
- 原A10互相搀扶镜头已替换为我军背枪在电报房内行走，镜头连续滑动，展示设备、家具、木梁与室内灯光。
- 检查口3名、木料巷4名、电报房4名守卫，另有第二门突袭兵和渡口守卫，共13名固定敌人。
- 木料巷第二道门有刺刀突袭；电报房击倒3名守卫后，最后一人再次发动同类互动。冲锋沿畅通直线推进，接近后才抬手夺枪，近身连续按空格反制。
- 电报房换为用户双拱顶建筑，名册移到南厅办公桌，总闸移到东北电话柜；伐木场建筑采用用户破房子合集。
- 渡口掩护解缆30秒，左上角倒计时。追兵固定每组2人，当前一组全部击倒后1秒补入下一组，至少达到旧版两倍的补兵频率。
- 登船转场后进入松岭屯。使用“东北农村”完整主聚落，保留22组院落及原村道，沿村口、转折巷道、北院推进。姜岚持枪支援，陆山在船边保管名册；逐段清除12名日军，打开两道院门，到北侧会合。
- 用户河道、木栈桥和小船用于两岸；鱼及无关展示物件未进入游戏派生版。开场广景结合完整村落、村边伐木作业点与实际青岚林场，原旁白和镜头时长保留。
- 电报房采用实际建筑表面碰撞和细化室内导航，封住木料巷右侧直达电报房的绕路；铁皮屋贴图内的红色英文已清除。
- 原林场实墙与任务门保留；村内沿原院落连接短门垛遮挡后续战斗。0.8米木桩铁丝网只封闭无任务支巷，碰撞与可见高度一致。
- 已接入用户提供的音乐、冲锋叫喊与11项音效，以及受伤时短暂泛红的屏幕边缘。

## 操作与路线

| 操作 | 按键 |
|---|---|
| 移动、冲刺 | W A S D、Shift |
| 蹲伏、跳跃 | Ctrl、Space |
| 射击、瞄准 | 鼠标左键、按住右键 |
| 换弹、切换武器 | R、1 / 2 |
| 互动、交谈、开门、拾取 | E |
| 自我包扎、行动记录 | Q、J |
| 对话选项 | 鼠标点击或1 / 2 / 3 |
| 刺刀近身反制 | 连续松开再按Space；长按不累计 |
| 暂停、开场跳过当前段 | Esc、Enter |
| 显示帧率 | F3 |

1. 看完或跳过开场可完成简报；选择“直接进入林场”时先与姜岚交谈。木棚里的林守义提供一次补给选择。
2. 清理检查口和木料巷的守卫，分别按E打开栅门；第二门后应对刺刀突袭。
3. 进入电报房，解决4名守卫及末敌突袭，取名册、拉总闸、接应陆山。可处理伤口，也可直接护送。
4. 带陆山绕电报房北侧前往渡口；靠近船边开始30秒掩护，结束后按E登船过河。
5. 与姜岚逐段清理松岭屯，清完本段敌人后按E开院门；全村12名日军清除后到北侧按E会合。

陆山等候、玩家离开渡口或暂停时，解缆倒计时暂停并保留进度。两种枪都没有弹药时，可在前两处栅门的应急补给点按E取5发步枪弹，再切到步枪换弹。

**体验当前完整布置，请开始新游戏。** 旧存档保留原遭遇配置；旧渡口完成档可接续登船，旧直线村庄档迁移到对应推进阶段并保留物资和击杀。村庄检查点保存院门、敌人和战友状态。

## 设置与存档

标题页和暂停菜单都可进入设置。包括三档画质、帧率限制、垂直同步、全屏、灵敏度、武器晃动及帧率显示。音量即时生效、显示百分比、自动保存，0%为静音；拖动音量不会重设窗口模式。

| 声音控制 | 影响内容 |
|---|---|
| 总音量 | 所有声音 |
| 背景音量 | 全局配乐，默认22% |
| 音效音量 | 枪声、拉栓、脚步、流水、爆炸、开关门 |
| 对话音量 | 人物对白、警戒语音、冲锋叫喊 |
| 剧情动画音量 | 两段开场的整体声音 |

历史录音中的旁白与配乐已混在一起，由“剧情动画音量”整体控制；该段播放时全局配乐停播。任务序幕中，各类声音同时受其分类音量与剧情动画音量控制。暂停后调音量再继续，录音保留原播放位置。

本地文件位于%APPDATA%\FenghuoEcho\：

- presentation_v1.cfg：显示、操控和声音设置。
- qinglan_checkpoint_v2.json：任务、物资、角色、守卫、栅门和撤离进度。
- QA测试使用单独的文件名，不覆盖正常试玩存档。

开场从当前段开头恢复，不从中断的某一秒恢复。新游戏会替换正常游戏检查点。存档损坏或写入失败时有可重试状态；不要在运行时手动改存档。

## 开发、构建与检查

在本目录打开PowerShell。试玩不需要安装Python或Blender；修改模型、备份和资源制作才需要相应工具。

```powershell
.\Start-Game.ps1                  # 从源码试玩
.\Start-Game.ps1 -Editor          # 编辑器
.\Test-Game.ps1                   # 源码回归与自动通关
.\tools\Verify-PolishRevision.ps1  # 两种分辨率、全屏实际拖动
.\Build-Game.ps1                  # 更新Release资源包
.\Test-Game.ps1 -Release          # 从源码目录外验证发布包
.\tools\Verify-PolishRevision.ps1 -Release
```

引擎优先取自tools/Godot-4.7.2/，缺失时再查本机安装。构建先输出临时PCK，成功后替换正式PCK。测试脚本、日志和验收截图不进入游戏资源包。

专项工具支持-Headless，但全屏、画面和实际拖动必须运行有窗口的检查。统一回归包含旧档、失败重试、暂停设置、枪械、刺刀、人物、音频、开场隔离、护送和撤离。最新结论见[验证入口](GodotProject/VERIFICATION.md)。

## 当前边界与接续

雪地、坡道融合、表演连贯性、音效音乐听审和完整真人试玩仍需继续验收。原A10扶人已取消，不再作为待补动画。其他硬件、手柄与跨平台体验尚未验收；自动通关不能代替真人难度和听感评价。

继续工作先读[PROGRESS.md](PROGRESS.md)，再读[production_plan.md](docs/production_plan.md)。production_state.json是唯一步骤状态来源，PROGRESS.md由备份工具生成，历史在work_history.jsonl。每个可验收小步保存检查点，恢复前核对清单、保留未备份改动。手动制作不自动开启接续面板。
