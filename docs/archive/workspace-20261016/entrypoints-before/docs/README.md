现有单关卡保留 1938 年东北抗联背景与青岚林场故事。新任务共有 9 名敌人，最多 6 名存活；初始 5 名，开启渡口栅门后两批各 2 名追兵。主线改为检查口、木料巷、电报房和渡口四段推进；救出陆山后在船边掩护解缆 12 秒，再共同撤离。

沿用此前的骨骼手部、21 项环境资源和 6 项外部录音；NPC 已使用 Blender 连续蒙皮人物，由现有程序驱动动作；下载的通用角色动画未接入。原有玩法短对白不会锁定镜头。S07 新增独立两段开场草案，播放时暂由过场控制镜头，并使用天池 DEM 远景参考；双人拖扶、正式表演、完整中文配音和 8–12 分钟节奏仍是后续制作与试玩目标。体验新开场请运行根目录 Start-Game.cmd；Release 仍是旧发布基线。

工程根目录的 `Test-Game.ps1` 运行基础、动作、剧情状态及正常 AI 通关检查；`-Release -Capture` 从源码目录之外运行正式包并截图。`Test-CombatPerformance.ps1 -Release -Label <本次标签>` 测量正常 AI 下自动移动与开火路线的帧时间，报告会注明敌我实际射击次数，不能把零敌方开火的结果称为持续双方交火。`Test-Performance.ps1` 为固定相机测试，必须与活动路线数据区别阅读。

`../GameProject` 是停用的 Unity 实验骨架。`../AssetLibrary` 是工程外库存，下载不表示已进入关卡；用户提供的商业游戏包仅作只读参考，没有导入其模型、声音或对白。
