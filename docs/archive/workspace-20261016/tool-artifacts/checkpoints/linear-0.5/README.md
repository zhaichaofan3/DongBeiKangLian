# 烽火回声 · 林海归途

制作版本 0.5，2026-10-12。1938 年深秋，东北抗联背景，虚构东南满“青岚林场”。这是继续制作中的可玩关卡。

## 启动

双击 `FenghuoEcho.exe`，保留同目录 `FenghuoEcho.pck`、引擎许可与素材来源说明。无需编辑器、账户或联网；整个 Release 目录可一起移动。

源码位于 `C:\GameMake\GodotProject`。双击 `C:\GameMake\Start-Game.cmd` 运行，或用 Godot 4.7.2 打开 `project.godot` 编辑。`Start-Game.ps1 -Editor` 可启动编辑器。

先与姜岚交谈，可向木棚里的林守义领取补给。路线为 **检查口 → 木料巷 → 电报房 → 渡口**。清理检查口岗哨后按 E 打开第一道栅门；木料巷两名守卫解决后打开第二道栅门。进入电报房取名册、拉总闸，找到陆山并让他跟随。绕房子北侧，打开渡口栅门，带他靠近船边，掩护解缆 12 秒后按 E 撤离。离开渡口、暂停或命令陆山等候时，解缆暂停并保留已完成进度。前两处栅门旁有应急弹药箱：两种枪的弹药全部耗尽时，在栅门按 E 补 5 发步枪弹，再按 1、R 装填，避免清敌要求造成卡关。

**新任务共 9 名敌人：初始 5 名，开启渡口路线后两批各 2 名追兵；最多 6 名同时存活。** 后续路段的守卫在对应栅门打开后投入战斗。追兵从固定道路入口进入，玩家靠近或正看着无遮挡入口时延后。敌人首发压制，后续交替瞄准射击；仍会造成伤害。自动测试的精准瞄准不能代表真人难度。

## 本轮制作

- 连续围挡收束主线，三处栅门衔接分段战斗，补充低矮掩体与方向牌。
- 目标提示增加相对方向箭头，开门和撤离提供当前步骤提示。
- 渡口增加 12 秒护送收尾；解缆无倒计时失败、无无限刷怪，仍需与陆山一起撤离。
- 检查点保存栅门、追兵与解缆进度；修正新路线上的木箱、钢轨阻挡和巡逻起点。
- 保留此前的武器、蒙皮双手、环境资源、七段行进对白及空间声音。

## 设置与存档

标题页或暂停菜单可选性能/均衡/画质，设置 60/120/144/不限帧率、垂直同步、全屏、音量、灵敏度、晃动和帧率显示。设置保存在 `%APPDATA%\FenghuoEcho\presentation_v1.cfg`。

检查点：`%APPDATA%\FenghuoEcho\qinglan_checkpoint_v2.json`。保存任务、物资、信件、门、绷带、陆山状态、敌人、增援、栅门和解缆进度。开始新任务覆盖当前检查点。旧版检查点继续兼容；没有线性流程记录的旧档打开所有新栅门，不追加解缆要求，并将陷入新增围挡的人物移到最近可走位置。没有遭遇记录的更早旧档保留 3 名初始敌人，可有 4 名增援。**体验本轮完整布置请开始新任务。** 测试使用独立 QA 存档。

## 构建与验证

在 `C:\GameMake` 执行：

```powershell
./Test-Game.ps1
./Build-Game.ps1
./Test-Game.ps1 -Release -Capture
./Test-CombatPerformance.ps1 -Release
```

便携 exe 是官方 Godot 4.7.2 标准二进制，约 173 MiB；启动后加载同名资源包。构建先导出临时 `.pck`，成功后原子替换。测试、日志、截图和 Markdown 不进入资源包。

统一测试覆盖基础功能、真实输入驱动的武器动作、短对白/空间声音恢复，线性栅门、保存恢复、解缆暂停，以及保留 AI 正常巡逻与射击的完整通关路线。`-Release` 从源码目录以外启动正式 exe/pck；`-Capture` 生成八种场景、1280×720 和 960×540 两种尺寸，共 16 张图。结果与证据见 `VERIFICATION.md`。

`Test-CombatPerformance.ps1` 使用 1920×1080 实际渲染路线，关闭垂直同步和帧率上限，输出帧时间与交火子集。`Test-Performance.ps1` 为暂停 AI 的固定机位测试，其旧版数值不能代表本轮关卡。

## 当前限制

- 距离《战地1：钢铁风暴》的最终标准仍有明显差距。NPC 仍为程序分节人物，下载的通用角色动作尚未重定向；枪械主体仍是程序模型，手枪、装填等部分声音仍为合成音。
- 袖子与手枪接触仍需逐姿态打磨，没有完整动捕、人物历史服装、面部表演或扶伤员成对动画。
- 已有短对白和任务闭环；分视角剧情、动态棚屋破坏、真人配音和音乐尚未制作。
- 友方不会受伤死亡，敌人攻击玩家且不主动寻找掩体。林场大部分远景仍为程序草木，没有整片森林破坏、车辆或多关卡。
- 尚未验收真人完整通关、8–12 分钟节奏、最低配置、其他显卡/平台或手柄；历史外观仍需考据。
- 中文使用 Windows 字体回退。来源见 `ASSET_SOURCES.md`，引擎许可见随包文件。工程外 AssetLibrary 的下载资源只有选用部分进入游戏。

开发接口连接问题见源码根目录 `docs/connection_diagnosis_2026-10-12.md`。离线运行游戏不依赖该服务。
