# 烽火回声 · 林海归途

1938 年东北抗联背景的原创单机 FPS，虚构地点为青岚林场。当前制作版本 **0.6**，使用 Godot 4.7.2 / GDScript / GL Compatibility。

双击 [FenghuoEcho.exe](Release/FenghuoEcho.exe) 运行，保留同目录 `.pck` 与来源说明；源码入口为 `Start-Game.cmd`。

本轮把四类人物接入 Blender 制作的连续蒙皮模型：补上头脸、眉眼和手指细节，重做棉衣与随身装备，并调整守卫双手握枪及倒地衔接。保留可编辑的 `.blend` 工程。人物仍偏风格化，后续继续打磨角色差异、服装年代细节与动作。

已有线性关卡路线：**检查口 → 木料巷 → 电报房 → 渡口**。围挡、栅门和路牌引导逐段推进，敌人分区投入战斗；救出陆山后沿电报房北侧撤离，到船边掩护他解缆 12 秒。目标提示增加相对方向箭头。

新任务保留 5 名初始敌人和两批各 2 名追兵，总数 9 名，最多同时存活 6 名；前两处栅门需清理当地守卫，最后一处需完成断电和接应。开启渡口栅门后追兵开始从固定道路入口进入，玩家附近或可见入口处延后出现。检查点保存栅门、敌人和解缆进度。

**请选“开始任务”体验新路线。** 旧检查点继续兼容，旧档的三道新栅门全部打开、不追加解缆要求；落在新增围挡内的人物会移到最近可走位置。画面和角色动作仍是制作中的原型，距离《钢铁风暴》的最终品质还有明显差距。
