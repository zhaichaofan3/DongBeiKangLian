# 0.6 人物细化验证记录

2026-10-12，Windows，Godot 4.7.2 / GL Compatibility。

## 源码与正式游戏包

`Test-Game.ps1` 和 `Test-Game.ps1 -Release -Capture` 均通过。每套包括基础 107/107、线性关卡 37/37、武器动作 43/43、剧情声音 11/11、人物模型 37/37，共 **235 项程序断言**。正常 AI 完整交火路线两套均通过，消灭全部 9 名敌人、救出陆山并完成掩护撤离，最终状态 won。

人物检查验证四类角色实际使用导入的蒙皮模型、13 根关节及有效权重、装备可见性、站立尺寸与落地、行走变形、双手握枪、后坐、受伤救治与倒地。握枪检查计算变形后手掌的位置，低持枪和瞄准均符合距离握点 5.5 厘米以内的要求；倒地检查覆盖从持枪和瞄准状态进入，确认无残留扭转。人物独立场景不读写游戏存档。

线性测试覆盖三门碰撞/寻路/顺序封锁、分段激活、门状态存档恢复、旧档兼容、畸形字段拒绝、缺弹兜底及其存档、解缆计时、暂停/离区/同伴等候停止计时与最终结束条件。

基础叙事测试隔离冻结敌人的碰撞，避免不行动的测试守卫堵住固定行走路线；正常交火测试保留敌人 AI、武器伤害与实体碰撞，并通过连续行走完成新路线及陆山护送，途中不传送。

`Build-Game.ps1` 成功生成正式包。发布验证从临时目录启动 `Release/FenghuoEcho.exe`，没有传入源码 `--path`，游戏脚本与资源由同名 pck 加载；测试控制器仍由工程 tests 目录读取。日志无 SCRIPT ERROR / ERROR。

## 画面检查

标题、设置、交谈、木料巷、电报房、救援、记录、渡口，分别在 **1280×720 和 960×540** 实际输出尺寸截图，共 16 张。本轮检查了正式包的交谈和救援人物在环境中的效果；线性路线与界面沿用 0.5。

另输出 **14 张 1280×720 人物截图**，包括四类角色全身与面部、合照、行走、瞄准、救治前后及倒地。人物截图运行结果为 51/51（37 项人物检查 + 14 项图片输出检查）。重点复核了头颈和下巴接缝、握枪手型以及倒地手臂姿态，未见此前修复的拉伸、浮手和残留扭转问题。颈部比例、肩部形态和武器轮廓仍有风格化特征。

截图位于 `Release/verification-captures` 与 `Release/character-captures`，共 30 张；这些画面由固定场景布置生成，不代替连续通关验证。

## 验证边界

自动控制器精准瞄准的通关不代表真人难度、紧张感或实际游玩时长。未进行新性能测量；历史固定机位或分辨率不符的交火报告不可用来描述本版帧率。四类人物共用基础脸型，服装未完成逐项年代考据，未接入动作捕捉或面部表情动画。画面与人物动作仍是风格化原型，尚未达到《战地1》的视听标准。
