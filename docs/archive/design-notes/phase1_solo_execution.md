# 单人制作执行方案

2026-10-12，版本 0.3。当前工程为 `GodotProject`，Godot 4.7.2 / GDScript。代码、人物、场景、音效、测试和打包由同一开发执行者完成；按质量条件推进，无固定完工日期。

当前范围为东北抗联背景《林海归途》：单地图、双枪、一种警戒兵、三个可交谈人物、林工补给选择、可治疗/跟随/等候的交通员、家书记录和共同撤离。

## 已完成的本轮增量

- 背景、任务文案、人物关系、记录与结局同步改写。
- 实际对话 UI、鼠标/数字选项、木门、医药包、包扎、护送与存档。
- 林区建筑、植被、道具、人物和枪械几何细化，材质、灯光与环境音更新。
- 功能测试与敌人正常活动的整关自动测试。

## 后续顺序

1. 依据完整试玩调整交火距离、首次引导与同伴跟随节奏。
2. 增强人物和枪械动作，进一步整理树冠、地表、建筑细节与光照。
3. 核查服装、林场设施、武器及抗联生活细节。
4. 实测时长、帧时间和最低配置，再决定扩展内容。

只添加能改善互动、叙事或空间判断的资源。当前全部自制，允许后续使用许可明确的免费与开源素材并登记出处。护送已进入当前版本；载具、多地图、复杂分支、更多武器仍后置。
