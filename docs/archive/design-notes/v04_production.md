# 0.4 制作记录：林海归途

2026-10-12。保留1938年东北抗联背景与虚构的青岚林场，以《战地1：钢铁风暴》的整体质感和普通人的局部经历为最终方向。本轮完成现有关卡的素材接入与玩法补强，仍属于可玩制作版，尚未达到参考作品的完成度。

## 本轮实际落地

| 部分 | 已进入游戏的内容 |
|---|---|
| 第一人称双手 | 接入 para 的连续蒙皮左右手，每只24根绑定骨骼；适配双枪、布袖、手指握持、扣扳机、拉栓和装填。持枪动作由项目定制，原资源的通用测试动画未使用。 |
| 环境 | 选用21项 Poly Haven 资源：12项模型、8项PBR表面、1项阴天HDRI。树根、倒木、苔石、蕨类、木箱、工具、油灯与电台进入林场，配合地表和建筑材质、冷天光与局部暖灯。 |
| 声音 | 实际使用6项外部录音：步枪、草土脚步、森林风、河岸流水、电台底噪和断电开关。河水与电台按距离衰减，电台在断电后停止。其余部分仍为合成音。 |
| 行进对白 | 新增7段短字幕对白，覆盖出发、干布、首次交火、断电、掉队、过路与河岸；按条件触发，保持玩家操作。它们尚无真人配音。 |
| 敌人与增援 | 新任务5名初始敌人，断电后两批各2名增援，总计9名，同时存活上限6名。增援从道路入口进入，入口靠近玩家或处于视野内时延后；敌人使用压制与瞄准射击。 |
| 检查点 | 保存敌人存活状态、伤血、增援进度、玩家弹药及剧情记录。兼容旧档；缺少新遭遇数据的旧档保留原3名初始敌人，完整新布置从“新任务”体验。 |

作者、许可与加工步骤见[实际素材来源](../GodotProject/ASSET_SOURCES.md)。资源库中尚未适配的枪械、人物和通用动作不计作本轮已接入内容。

## 一关的任务闭环

与姜岚接头 → 向林守义求助，选择绷带或弹药 → 穿过运材场、进入电报房 → 取回搜山名册并切断中继电源 → 接应陆山，可包扎、跟随或等候 → 共同到达渡口并确认撤离。

名册、家书和陆山的短对白把目标落到具体的人。撤离需要任务条件满足、陆山到场；普通战斗死亡仍走检查点重试。当前只有这条现有主线，分视角交接、剧情损失与双人拖扶表演尚未实现。

## 与最终目标的差距

枪械仍有低模轮廓，NPC仍为程序分节人物；手指与枪机接触、衣袖形变、年代服装、步态与面部表演需要继续精修。环境已有真实材质和扫描道具，但树冠、建筑破损、烟尘层次、光照统一及战场事件密度仍明显弱于《战地1》。完整机械音、中文对白演出和最终混音也未完成。

下一步应先完成60–90秒质量样板：持枪移动、短交火、拉栓装填、扶伤员过门，逐项检查动作接触、声音同步、场景层次与实际帧时间。整关达到参考作品同等画质和规模，目前没有验证依据；8–12分钟节奏仍需真人试玩确定。
