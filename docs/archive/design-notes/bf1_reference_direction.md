## 最终画面标准

1. **首先做好镜头近处。** 双手为连续蒙皮网格，指节、拇指根和腕部变形可信；袖口有厚度与粗糙度。枪机、照门、枪托握持和装填接触在正常速度与慢放下都成立。不能靠晃动和模糊隐藏穿模。
2. **场景要有使用与破坏的痕迹。** 林场有运材痕迹、湿木端面、车辙、泥水、散落工具、破损棚墙与地面高差；局部损坏服从事件。石头、植物、木材的比例和色调必须统一。
3. **冷天光，有限的暖火光。** 深秋阴天、湿地、层次清楚的远近雾。火只照亮附近表面；金属、湿泥和布料有不同高光，避免全场像涂了同一层亮漆。
4. **烟尘有起因、方向、寿命和密度变化。** 击中泥土、木材、墙体有不同效果；爆炸后短时间遮挡并逐渐散去。用少量重点事件和远处战事暗示更大的包围，不要求整片森林实时可破坏。
5. **人物通过身体说明状态。** 警戒、弯腰、踉跄、拖扶、递物和转头有区别；跑步不滑脚，伤员不能按健康士兵的速度移动。面部近景只在表情与材质实际过关后使用。
6. **声音表现距离与处境。** 近枪由枪口声、机械声、弹壳和尾音组成；远枪变薄、被地形遮挡；屋里有短反射。脚步按地表改变，奔跑有衣料和呼吸。冲击后的短暂听觉变化为可调效果，控制峰值。

“小视角”主要指叙事范围和信息范围，不等于把视场角强行缩得很窄。保留舒适的视场角、晃动与动态模糊设置；通过遮挡、路线、人物距离和事件调度控制注意力。

## 原创关卡提案：把名字带回去

背景仍为 **1938 年深秋，虚构的东南满青岚林场**。主线保留搜山名册、断电和伤员撤离；用名册上的人名、林工的日常物件、没有完成的承诺串起故事。目标体验 8–12 分钟，实际时长须真人试玩测量。

| 段落 | 视角与局部目标 | 事件与可玩内容 | 情绪与必需资产 |
|---|---|---|---|
| 0:00–1:20，棚里的灯 | 林工林守义，把水递给伤员，把孩子留下的手套收进衣袋 | 近距离递物、听到外面脚步、熄灯；他认得名单上的人 | 先建立人的生活；手、袖口、水碗、布、油灯，短互动动作 |
| 1:20–3:30，只隔一条运材道 | 沈砚，与姜岚会合，接到林守义递来的路线 | 沿倒木与木料堆低姿通过，第一次短交火，敌人的火力迫使人伏低 | 敌我都具有威胁；可靠掩体、压制反馈、持枪移动、受击与倒地 |
| 3:30–5:30，名单别沾水 | 沈砚，进入电报房，取名册并切断警报线路 | 门外有威胁，屋内找物不靠长时间搜集；陆山就在隔间 | 任务落到具体人名；电台、纸张、门、保险箱或木柜、扶起动作 |
| 5:30–8:00，二十米 | 沈砚，将陆山带到下一处遮蔽；姜岚提供火力与路线判断 | 伤员可跟随/停留，短距离分段转移；木棚受损，原撤离路被封；林守义去解渡口缆绳后没有按时回来 | 残酷感来自不能同时照顾所有人；拖扶/包扎/踉跄、木屑烟尘和衣物声音 |
| 8:00–10:30，剩下的人 | 姜岚的短暂接应视角，完成沈砚被迫中断的撤离任务 | 明确的剧情交接点切换，不把普通玩家死亡自动当故事进度；掩护陆山和沈砚登船 | 接过责任而非连续升级火力；共用骨架与武器资产、短交接动作 |
| 10:30–12:00，渡口 | 幸存者共同撤离 | 船离岸后看见空位、沾水的名册与林守义留下的物件；用简短对白确认失散，不以击杀数庆祝 | 结尾安静收束；船、手部特写、远处枪声、呼吸与水声 |

以上时间是段落预算。林守义是否牺牲在结尾只给与剧情证据一致的信息，不将未经确认的失散直接写成死亡。人物是虚构，历史背景与装备另做考据。

**叙事借鉴：** 普通人有限的视野、无法独力改变战局、倒下之后任务仍需有人完成，以及近距离人与人的联系。对白、人物关系、事件、地理路线与结尾为本项目重新创作；不逐场搬用参考中的机枪—坦克—毒气顺序。

**玩家规则：** 普通战斗死亡保留读档与重试。若设置确定的剧情损失，应通过明确事件和表演呈现，不靠悄悄锁血或无限刷兵强迫失败；也不让玩家因坚持救人而被脚本羞辱。任务提示重在“到那根倒木后”“扶他过路”，避免持续刷击杀奖励破坏情绪。

这一版分视角段落尚未写入现有游戏逻辑。0.4 保留原有任务与护送闭环，增加短对白、敌人/增援状态和对白触发记录；尚未制作本提案的视角交接与剧情损失。

## 先制作 60–90 秒可玩质量样板

场地：约 20×30 米，湿林道接破损木棚，2 名友方、最多 3 名敌人。一把经过型号核对的栓动步枪、一套蒙皮双手袖子。流程为接物 → 穿过倒木 → 短交火 → 拉栓/装填 → 将伤员扶到门后。

| 验收项 | 判断方法 | 当前差距 |
|---|---|---|
| 手与枪 | 同一机位录制正常速度及 0.25 倍慢放；检查指形、抓握、枪机、弹药入膛时点、瞄准线 | 0.4 已接骨骼双手与定制指骨/腕部动作；精细枪模和全部接触姿态仍需打磨 |
| 环境 | 阴天和火光两个状态，从正常移动视角检查材质与轮廓，不仅看摆拍截图 | 0.4 已选用 21 项模型/材质/天光资源；树冠与建筑轮廓仍有明显低模感 |
| NPC | 行走、停步、转向、受击、扶人；检查脚底与地面、双人接触 | 已获得通用动作和人体，年代服装与成对救援动作待制作 |
| 声音 | 对齐射击、拉栓、脚步与门事件；用室内/室外两处比较层次 | 六项录音已接入，新增河水/电台/断电；完整机械声音、对白和混音待制作 |
| 叙事 | 不解释背景先让首次玩家试玩，确认知道要救谁、下一处掩体在哪、为何要撤 | 已有任务闭环与 7 段短对白；新分视角和双人短表演未实现 |
| 性能 | 本机 1080p 实际交火 60 FPS 目标，记录完整帧时间与显存，包含烟尘和 NPC | 旧原型静态高 FPS 不能证明新样板能达标 |

先在现有 Godot 管线做样板。Forward+ 的体积雾与光照单独对照验证，再确定正式渲染器；材质与动作问题不能靠更换引擎消除。当前 RTX 5060 Laptop 8GB / 32GB 内存可用于样板开发与实测，但没有证据保证整关达到 BF1 同等质量、同等规模与帧率。

## 本轮资源如何对应目标

- [资源总目录](../AssetLibrary/README.md)：下载、导入验证、实际接入分别记录。
- 双手：MakeHuman 来源连续皮肤网格 + 骨骼，先修复材质/尺度，再制作握持和同步动作。
- 人物：Quaternius 65 关节身体与通用动作用于行走、蹲伏、受击；不能把通用手枪装填直接套成步枪第一人称装填。
- 环境：Poly Haven 扫描材质、树根、倒木、石头、箱子、油灯与电台，配补充树木和棚屋原料；依据林场风格重组。
- 声音：真实枪声、脚步、林风、电台与木门；按事件、空间和年代需要选取，保持原始来源与派生步骤。
- 尚缺：适合近景的目标枪械活动部件、专用双手动作、抗联与敌军服装、可信表情、扶伤员成对动作和最终中文对白演出。这些是接下来的制作工作，不计为已下载完成品。
