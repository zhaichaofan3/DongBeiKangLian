# 青岚林场资产清单

2026-10-12，版本 0.3，东北抗联场景。尚无用户提供的参考图，以下是对当前原创关卡的分层，不声称来自图片分析。

| 层次 | 优先级 | 资产组 | 当前结果 |
|---|---|---|---|
| 前景 0–15m | P0 | 双枪、手臂、弹药反馈 | 圆枪管、枪机、照门、金属箍、握把纹理和装填姿态 |
| 前景 | P0 | 姜岚、林守义、陆山和警戒兵 | 共用人物结构，角色配色/帽子/包扎不同；五官、衣袋、围巾、绑腿、背包和行走/交谈动作 |
| 前景 | P0 | 名册、总闸、医药包、家书、木门 | 已实现交互、状态变化与恢复 |
| 前景 | P1 | 电报机、桌、木凳、炉体、烟囱、档案架、地图 | 已加入场景，设备精确外观仍待考据 |
| 中景 15–60m | P0 | 林工木棚、木墙、检查口、电报房 | 已实现，门洞/墙体/桌边/主路线经移动测试 |
| 中景 | P1 | 坡屋顶、窗框/玻璃/窗台、柱、梁 | 已增加建筑层次，窗户当前是静态外观 |
| 中景 | P1 | 运材轨道、圆木堆、平板货车、木箱 | 已实现静态视觉与掩体，无驾驶 |
| 中景 | P1 | 灯笼、护条、灯座、栈桥、系船桩、木船 | 灯与发光同步关闭；板缝等视觉细化 |
| 中景 | P1 | 松树、桦树、草丛、落叶与河岸石 | 自制几何，草丛使用 MultiMesh；装饰植被不全部带碰撞 |
| 背景 60m+ | P0 | 林溪、对岸林舍、松桦林、远山、天空和雾 | 已加入，远景不可到达 |
| 全局 | P0 | 地表、木、砖、瓦、金属、布、树皮、叶、石材 | 256px 程序纹理与 mipmap，地表减少接缝 |
| 全局 | P0 | 对话、选择、记录、同伴状态、菜单 | 已实现中文 UI 和键鼠选项 |
| 全局 | P1 | 林风、短鸟鸣、战斗与操作音效 | 自制 PCM，风声循环 |

P0 为可玩和识别必需，P1 为展示与氛围。后续 P1：更自然的武器/人物动画、树冠形态、色彩和历史服装器物考据。P2：额外建筑群、载具、更多人物职业、音乐与完整配音。

所有素材当前由工程生成；实际许可见 [ASSET_SOURCES.md](../GodotProject/ASSET_SOURCES.md)。照片级纹理、外部模型和真人录音尚未引入。
