# 东北抗联背景与考据记录

2026-10-12，版本 0.3。当前创作定位：1938 年深秋，东南满林区，虚构青岚林场。主角属于东北抗联的一支虚构小分队，不使用真实番号、将领或真实战役名称。

## 已实施的叙事调整

从华中沿江任务改为林场侦察与交通员接应。名册关系到密营、联络点和山下接济者的安全；林工参与提供情报与物资。人物使用当面接头、纸质名册、电话中继和步行撤离，避免随时无线电通话的现代行动习惯。

玩家装备改称“缴获步枪”与驳壳枪，暂不把简化模型对应到确定型号。服装采用棉衣、围巾、绑腿和混合朴素配色，不添加未经核实的军衔徽记。

## 表达

把冲突归于侵略、占领组织及具体行动，不将民族或平民整体当作敌人。强调抗联战士与当地劳动者之间的互助关系，任务目标同时包含情报和同伴。人物与行动全部虚构，不代真实人物发布命令，不将真实惨案做成积分目标。

友方保护是当前玩法取舍，不声称是史实行为模拟。通关文字重视一起撤离与获得帮助，不以击杀数量评判救援的价值。
