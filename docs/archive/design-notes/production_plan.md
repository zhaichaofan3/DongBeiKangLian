## 3. 设计判断与执行顺序

- **先锁定叙事和任务接口，再精修镜头。** 先用现有场景做简化镜头验证节奏；人物、场景、音效完善后替换占位内容，降低返工。
- **沿用现有线性任务作为实际基线。** 之前讨论的“山林—村落—林场—天池—突围”是概念方案；S03 设计确定天池谈话为数日前的开场前序，经行军剪辑转入现有林场，具体空间布局在 S08 确定，不能直接替换电报房和渡口任务。详见 [S03 故事与任务接口](S03-narrative-and-mission.md)，新增演出尚待实现。
- **每组资源都有记录去向。** 用于正式场景、过场、远景、改造或备用都要明示；原始包、重复格式、偏日式造型、现代设施或超高面数零件，不因“所有资源”就全部堆入近景。
- **先解决动作连续性和脚步接地，再增加角色差异。** 原地动画和真实移动速度共同校准；持枪、受击、倒地与任务状态联动。
- **天池服务构图和人物。** 保留环形山壁、深蓝湖面、山脊和开阔感，适当加强包围感与纵深。近景岩台密度高、远景山体简化；视觉尺度通过镜头和步行测试决定。
- **战争规模由层次构成。** 前景人物交战、中景掩体与落弹、远景烟尘和火线配合；活跃战斗单位与粒子数量服从性能预算。
- **声音先试听，再分层接入。** 旁白与对白优先可辨，枪声、爆炸、环境和音乐保留各自动态；脚步、开火、受击要与动作同步。
- **美术验证与运行验证分开记录。** 导入通过、自动通关和静态截图分别说明不同问题；人工观感、角色表演和交火帧时间仍需单独检查。

## 4. 第一部分：历史序章

目标时长暂定 **75–90 秒**，最终跟随旁白实录和停顿调整。先展现山河、乡土和敌后处境，再进入战斗高潮，以天池大远景收束。

### 用户指定旁白（完整原文）

> 作为中国共产党创建最早、坚持抗日时间最长、条件最为艰苦的抗日武装力量，东北抗日联军在民族危亡之际，高擎抗日救国大旗，在白山黑水间、在冰天雪地里、在茫茫林海中，孤悬敌后，进行了艰苦卓绝的斗争。忠诚于党的坚定信念、勇赴国难的民族大义、血战到底的英雄气概，这是战火磨练铸成的东北抗联精神，也是中华民族在每次危难之际迸发的复兴强音

该文本为本方案的固定输入。制作旁白节奏、字幕分行和镜头表时保留原文，不将草拟对白或新增史实混入这段。

## 5. 第二部分：任务序幕

目标时长暂定 **60–90 秒**。参考《使命召唤14》开头的节奏：战友相处 → 人物关系 → 任务交代 → 危机升级 → 玩家接管。使用本游戏场景与原创对白，不照搬其人物、台词或诺曼底情境。

| 分段 | 场景与内容 | 所需动作与衔接 |
|---|---|---|
| B1 短暂休整 | 数日前，沈砚与姜岚在艺术化天池避风岩台停留 | 第一人称手部与姜岚反打，站立呼吸、看湖、整理装备、转头 |
| B2 战友闲谈 | 简短交流表达对家乡、生活与未来的牵挂 | 说话、听话、视线、少量手势、停顿与重心变化 |
| B3 交代行程 | 姜岚说明赴林区接头、接应陆山的原定安排 | 指向离开方向、检查装备；此时不提前宣布陆山昨夜被扣的新消息 |
| B4 离开高地 | 两人进入山路与树林，压缩数日行程；姜岚先行侦察后会合 | 转身、起步、走跑转换；明确时间与地域转场，不暗示林场紧邻天池 |
| B5 危机出现 | 到青岚林场，姜岚交代林师傅的新消息：陆山受伤被扣、名册在电报房；岗哨动静加压 | 讲清取册、断电、救援与渡口撤离；急停观察，演出不激活正式战斗 |
| B6 玩家接管 | 镜头对齐既有玩家起点，姜岚留守回山方向 | 正常结束／跳过统一提交已简报状态；保留可选木棚补给，不重复要求首次交谈 |
