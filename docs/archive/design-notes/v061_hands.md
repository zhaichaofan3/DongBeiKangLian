# 0.6.1 手部模型与握枪完善

2026-10-13，接续上次中断时已保存的 0.6.1 动作改动。

## 已保存的模型改动

双手基础继续使用 para 的 CC0 连续蒙皮。焊接 UV 接缝的几何重复点后做一级细分，改善手掌、指节和指尖轮廓；颜色贴图沿用原资源。每只手从3,356增至20,136个三角形。保持每手24骨及游戏使用的原始绑定坐标，插值并归一化权重。可编辑源文件在 `AssetLibrary/first_person/field_hands/field_hands.blend`，生成入口是 `tools/refine_fp_hands.py`。

原圆柱袖口改为贴合腕部的椭圆开口与翻边，加入布料纹理、两道缝线和布扣。袖子沿曲线离开手腕再连接前臂，横截面连续运输，避免参考轴切换产生突然扭转；闭合处 UV 不再跨整圈回卷。袖口、袖子仍由运行时动作生成。

## 上次动作改动的收尾

重新验证并保留步枪向上抬栓、手指跟随拉柄、托手稳定、回握以及驳壳枪食指位置修正。此前被中断的改动位于 `fp_hands.gd`、`fps_player.gd`、`human_model.gd` 及相应动作检查中，本轮与细化模型一起打包。

源码动作验收通过50项，带图运行另通过10项图像输出检查。截图覆盖步枪持枪、瞄准、抬栓、后拉、推回、装填开启、递弹夹、压弹，以及驳壳枪持枪和装填。另有两种武器各两个侧面的近景，已检查持握与腕袖连接。

本轮细化后，驳壳枪食指表面到扳机线段的最近距离约10.6毫米；此检查说明进入扳机区域，并不等同于逐面零穿插验收。拉柄检查用拇指／中指关节中心作为握持代理，不能将其误差当成手指表皮的实际接触误差。

## 仍需继续制作

目前仍是风格化原型。细分没有新增皮肤毛孔、指甲与皱褶雕刻，握枪和装填仍由程序驱动。后续适合继续手指软组织变形、手掌贴合枪身与压弹接触、独立皮肤粗糙度／法线细节。拉栓时右袖仍会占据视野右侧，需结合连续试玩进一步取舍。未重新测量帧率，网格增加后的性能不能用旧报告代替。
