# 技术可行性与验证

2026-10-12，版本 0.3。当前路线 Godot 4.7.2、GDScript、GL Compatibility。

## 结构

| 文件 | 责任 |
|---|---|
| `world.gd` | 模块化地图、程序化材质、林地细节、灯光与 AStarGrid2D |
| `fps_player.gd` | 玩家碰撞、双枪、弹药、生命与姿态 |
| `guard.gd` | 巡逻、搜索、物理视线与射击 |
| `human_model.gd` | 共用人物外形、五官、服装细节与简化动作 |
| `friendly.gd` | 面向玩家、跟随、等待、治疗速度与物理移动 |
| `story.gd` | 对话、选择、资源、阅读、人物状态与叙事快照 |
| `mission.gd` | 任务主状态、检查点、增援、菜单模式和输入 |
| `hud.gd` | 对话面板、菜单、记录与同伴/目标 HUD |
| `audio_factory.gd` | 原创操作音和林风循环 |

独立叙事标记与四状态任务结合，避免为每次交谈创建新的主关卡状态。对话和日志模式暂停交火；重要选择保存一次性奖励标记。门的碰撞和寻路网格同步。护送使用实际路径与碰撞，没有远距离瞬移追随。

## 验证

`tests/smoke.gd` 覆盖 70 项机制，包括数字键选项、J 日志、Esc 返回、门开闭和防夹、补给幂等、治疗、等待/跟随、信件记录、快照恢复、增援、完整同行路线、坏存档，以及渡口范围内继续与等候同伴交谈并完成撤离。

`tests/combat_route.gd` 保留所有敌人的正常 AI 与开火，由确定性控制器走完任务、实际射击、护送并完成收尾。控制器自动瞄准，因此仅验证系统集成与可达性，不用于估算玩家难度或正常时长。

两项测试顺序使用独立 QA 存档，避开玩家存档。截图通过实际 NVIDIA OpenGL 渲染获得，验证对话、字形、室内/室外、菜单和记录布局。

## 当前边界

人物为自制程序化低模，无完整骨骼混合树；友方无伤害状态，敌人只攻击玩家。大多数草木和远景是装饰。设置只在会话内生效。存档 v2 与旧场景 v1 分离。

帧率、最低硬件与 8–12 分钟体验仍待实测。1080p 60 FPS 为目标。下一次扩展优先处理交火节奏、导航极端位置、动作和考据，暂不叠加第二关或新敌人系统。
