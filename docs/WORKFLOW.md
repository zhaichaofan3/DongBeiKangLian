## 版本与发布

大模型、原包、纹理和音频用Git LFS。克隆前安装LFS，克隆后 `git lfs pull`。提交前检查 `git status`、`git diff --stat`、`git lfs status`，不要提交缓存、安装目录、私人会话或令牌。

提交是本地记录，推送是远程副本。未提交改动和未推送提交仍只在本机。重要试玩包通过版本标签与GitHub Releases保存，源码和生成包分别验证。

## 大小控制

- `.godot/`可重建，首次导入会再占空间，不进Git。
- `Release/`只留当前包，历史包存Releases。
- 模型保留当前编辑源和必要输入，原压缩包不重复拷入备份。
- 验证保留最终文字、故障原因及少量画面，查明问题后删除重复截图和大转储。
- 整理先列目标、核对依赖，删除结果写docs/maintenance。
