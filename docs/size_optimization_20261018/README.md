# 0.7.3资源体积与正式名称修订

正式名称：**东北抗联 烽火回声**。目标是将Windows安装EXE和免安装ZIP各自控制在1,000,000,000字节以内，保留实际关卡、原图质量和用户原录音。

## 已完成的游戏资源修订

- 原PCK为1,361,037,536字节，1,101项；新PCK为823,868,320字节，675项，减少537,169,216字节（39.47%）。新SHA-256：`1deee8f8f08c7c5a3efd8965811dc038d998e337c8d74bee215b56fb999379ec`。
- 原包贴图占1,209,809,474字节。后导入脚本按原图SHA-256与完整导入参数匹配，让126个贴图别名共用资源；新包贴图占738,836,686字节。保留的216份贴图与旧包逐项MD5一致，PCK所有文件内容均重新校验；没有降低原图分辨率、压缩质量或法线精度。
- 未使用的`village_complete`整村展示模型及其专用贴图只从玩家包排除。实际关卡仍是原农村派生的12组大院与3处穿院，近景建筑/山林、碰撞、战友、剧情、原有远景LOD及画质档位保留。
- 302个原始扩展GLB/图片与Git LFS对象SHA-256一致；127个用户录音及手部文件与既有保护清单一致。原件继续保存在工程/素材库，没有新增全量备份。
- 窗口、标题、暂停、开场标题卡、玩家文档、安装定义和快捷方式统一名称。保留内部EXE/PCK名称、正常安装AppId、安装目录与存档路径以兼容已有版本。

导入规则见`GodotProject/tools/`，生成入口为`tools/configure_delivery_assets.gd`。生成清单不是运行时依赖，随导入后的场景保存资源引用；制作工具不进入玩家PCK。`before-pack.json`与`after-pack.json`保留完整包目录、大小与文件摘要。
