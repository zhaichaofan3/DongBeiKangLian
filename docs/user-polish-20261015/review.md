## 验证与证据

最终发布验收汇总以[final-validation.json](final-validation.json)为准，文件完整性见[package-integrity.json](package-integrity.json)。这两个文件在完整回归结束后生成；缺失时表示尚未完成最后封包。

- [源码完整回归](source-regression.log)：22组、657项断言，离台21点采样，正常AI战斗路线通关，击倒19名敌人、剩余生命91。
- 发布包从源码目录外启动，使用交付的exe/PCK；[完整回归](release-regression.log)22组、657项断言全部通过，离台21点采样及19敌通关通过，剩余生命91。
- 源码与发布包分别在1280×720、960×540完成画面专项，每组43项、8张画面。证据位于source-render-1280、source-render-960、release-render-1280及release-render-960。
- 五个音量滑块均发送实际鼠标按下、拖动、松开事件，确认数值变化、全屏模式及尺寸保持，并检查设置保存和主动退出全屏后的窗口位置、尺寸恢复。
- 3米、7米、12米冲锋分别采样。显示中袖长最大约0.755米，最终握点间距约0.009米。该数值验证接触与长度限制，不能替代连续动作的主观观感。
- A10检查连续运镜、背枪行走、家具通行、专用灯光清理和任务隔离。已复查发布包室内画面、近战画面及全屏设置画面。

首轮发布完整回归曾在战斗路线启动时发生一次原生访问异常，退出码-1073741819。单独复测及串行完整回归已通关，首次原因未确定；另外补测有画面的战斗路线，结果见[实际渲染通关日志](release-combat-rendered.log)。原始失败日志与系统事件均保留，详见[迭代记录](iteration-notes.md)。最终通过结果不抹去此项失败证据，也不表述为已定位或修复该原生异常。
