# 本轮排查与迭代

当前最终结论以final-validation.json为准，本文件记录制作中实际出现的问题，避免把全部尝试描述为一次成功。

1. 初次导入发现备用帽星几何的局部变量类型推断报错，补显式浮点类型后重新运行。
2. 初版专项提前访问尚未创建的开场节点，补实例有效性判断；行走高度使用精度容差，避免把Vector3单精度的0.08当作动作失败。
3. 近战首次限制袖长后，最终握点偏离约0.147米；将近身枪身位置向玩家拉近并同步反制起始位置，重新测量至约0.009米，保留袖长限制。
4. 冻结界面的专项中保留了标题菜单，导致设置控件被刷新而找不到；显式切换专项显示状态，重跑真实拖动，避免将测试控制器问题误写成游戏修复。
5. 逐帧预览复查发现友军仍套用战斗持枪动作，改为背枪与正常摆臂行走。新室内聚光灯给衣服造成明显自阴影斑块，将布景灯与人物受光分层并降低过亮桌面，再次复查画面。
6. 完整源码回归先通过一次；目录、灯光与文档完成后再次运行最终源码回归。发布包另行构建，并从源码目录外复测。
7. 首轮发布完整回归在战斗路线启动后发生一次原生访问异常，退出码-1073741819（0xc0000005），没有GDScript错误或通关输出。保留release-regression-first-failed.log、combat-route-first-failed.log及Windows事件crash-event.json。单独使用同一发布包复测通过：19名敌人、生命91、耗时103.13游戏秒。首次原因尚未确定，不据此宣称已修复崩溃；随后串行重跑完整回归，最终结果另见final-validation.json。
8. 串行发布完整回归已通过22组、657项断言及21点离台采样；随后单独补测有画面的发布战斗路线同样通关，击倒19名敌人、生命91、耗时103.13游戏秒。未在这两次后续检查中复现首次原生异常。

不保留被取消的扶人接触断言作为验收要求。旧扶人设计和旧截图留在历史证据中，当前镜头及测试均采用电报房行走。
