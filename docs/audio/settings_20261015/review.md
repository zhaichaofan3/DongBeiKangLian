# S30 四类音量设置（2026-10-15）

本轮按用户最新要求增加背景、音效、对话和剧情动画音量，并保留总音量。四类支持0–100%、百分比显示、即时生效、自动保存和旧配置兼容。背景默认22%，其余新项默认100%。

- 音效覆盖 Weapons、Foley、Ambience：枪声、拉栓、脚步、流水、爆炸、门声等；原对白避让在用户音量之上叠加。
- 对话覆盖 Voice：任务序幕对白、发现敌人语音及刺刀冲锋叫喊。
- 剧情动画为两段开场的整体音量。A段用户完整混音直接走 Cinematic；无法单独拆分录音内旁白和配乐。B段各类别经过 Cinematic 后进入总音量。
- 暂停中调整立即生效，不恢复播放、不重播或跳字幕。跳过/结束/退出开场立即恢复普通游戏路由。
- 设置页面加入滚动区域，四项声音置顶，返回按钮固定。修复按钮回调期间同步销毁自身导致的菜单报错，改为立即移出布局、帧尾释放。
