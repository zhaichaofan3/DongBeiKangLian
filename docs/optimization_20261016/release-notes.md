# 0.7.2-rc1 本地试玩修订

- 树林空间分块与重复院落合批，减少视野外场景的绘制，保留树木数量和碰撞。
- 改进日光、雾、近景阴影、地表细节与斜视角贴图清晰度。
- 性能/均衡/画质三档分别调整抗锯齿、几何细节及阴影，原生分辨率保持不变，默认均衡。
- 优化薄墙/低网的导航准备；开始与读档等待场景准备完成。首次加载仍需时间。
- 使用内置Jolt物理并缓存人物场景，处理上岸时战友首次接地的数秒停顿。
- 环村山岭外移，避开整条入村密林土路；土路转弯改为连续网格，修正渡口地面/河岸/栈桥重叠、阴影条纹与细水纹闪动。
- 调整左手大小与护木接触；保留原手部模型，装填按实际缺弹数显示子弹，拇指压弹后退出空夹并闭锁。
- 保留现有两关剧情、窄街穿院、蹲伏探头、下游渡河、原手部与用户录音。

本轮验证以`release_validation.json`为准，文件完整性见`SHA256SUMS.txt`。渲染机位数据不等于实战帧率，不承诺所有视角或其他硬件同等提升。真人难度、听审、连续美术与表演仍待验收。本次只更新本地包与仓库，在线试玩包仍为0.7.0-rc1。
