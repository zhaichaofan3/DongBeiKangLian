# 性能与画质优化验收

版本0.7.2-rc1，基线为0.7.1-rc1。当前仍在验收；最终结果以本目录`final-validation.json`与根`PROGRESS.md`为准。

## 修改范围

- 首关604棵树、上岸密林2017棵树、村内180棵树、环村751棵树按64米空间分块，采用局部包围盒供视锥裁剪，保留全部原实例。
- 原东北农村12组大院按纵向段合批，保留原模型层级和碰撞。500米外建筑不再参与当前章节镜头，远山仍为独立背景。
- 三档画质分别设置关闭/2倍/4倍MSAA、3/2/1像素几何细节阈值、1024/2048/4096阴影贴图及42/72/96米阴影距离。均衡为默认档，分辨率不随档位降低。
- 贴图使用8倍各向异性过滤；调整中性环境光、暖日光、雾与阴影偏移，增加村庄地表法线及大尺度纹理变化。
- 薄墙和低网仅在各自包围范围更新导航占用，保留原胶囊物理查询。标题页在两关导航准备完毕后开放开始与读档，加载本身仍需时间。
- 原剧情、线性战斗门、道路、手部和录音保留；本轮未更换模型或扩大地图。

## 验证方法

源码串行回归32组。独立包从工程目录外启动，选择基础集成、线性路线、院落操作、渡河、首关、农村碰撞及任务扩展7组，并追加有画面画质39项、地图54项、导航指纹与实时完整战斗；未重复声称本批执行全部32组包回归。画质检查逐实例核对树林包围盒。导航以村庄和上岸点出发、开两道阶段门后的四邻接可达图比较旧包，预期79,589格，SHA-256为`bf6c80496a4ce18b9ea367c8041bf4c5aa3cc68887e509a3e9974dfed7906980`。

性能使用本机RTX 5060 Laptop GPU、Godot 4.7.2、GL Compatibility，1920×1080原生分辨率，关闭限帧和垂直同步。八机位缓慢转头，每处预热1.5秒、实测5秒，角色物理暂停，截图在计时外；这仅测渲染负担。完整战斗另使用真实时间、敌人AI与双方实际开火，不用固定模拟速度，统计移动/近期开火与静止区间及长帧。

旧包SHA-256为`cb08eea5f35ea686d422d1781e1ce8759d99f407741b24c14db7b61447e0852b`。原包与源码初轮样本存在焦点和运行时段差异，不取其中最有利数字宣传。最终独立包数据、原始JSON与日志随本目录保留，各视角变化必须完整披露。

## 中断与限制

首次源码全量回归在战斗测试的120秒时限停止，日志保存在`failures/source-combat-timeout.log`；独立延长测试随后37敌、生命100通关，最终存档有效。已将完整路线的测试时限改为600秒，其他检查仍保留原时限。固定速度回归只验证功能，其运行速度不作为性能证据。

本轮不承诺所有视角均提高帧率：树林分块减少多余几何，但局部批次和画质改进也有开销。初次场景装配与导航仍有明显加载成本；真人难度、声音听审、连续人物表演/美术及其他硬件仍待验收。
