# 用户人物模型替换

2026-10-15，归入S19人物修订。用户提供日军与志愿军RAR，要求替换外部人物，明确保留自己的手臂。

## 已接入范围

- 日军使用包内军帽、制服、弹药包和长靴人物，保留红圈与八字胡标识。原模型是军帽，未把它写成钢盔模型。
- 姜岚、陆山与开场我军使用志愿军冬装模型，军服派生为灰色，帽前添加红星。包内有两个同型人物，选取第一套适配。
- 我军与日军各使用独立GLB，接入原13骨驱动，继续使用现有行走、交谈、瞄准、受伤、倒地与刺刀演出。开场我军保留原持枪动作并指定友军外观，避免误用日军模型。
- 林工继续用原平民模型。NPC握枪接触手网格沿用已有第三人称成果；玩家第一人称手臂、袖子与武器未替换，逐文件核对见first-person-before.json及最终汇总。

## 转换与修订

两个包均只有MAX和贴图，没有FBX/GLB。本机未发现3ds Max。使用已留存源码的Blender MAX Importer读取几何和UV，未执行场景内脚本。日军读出11,106个三角面；志愿军两套共90,274个三角面。此转换没有取得可直接使用的蒙皮或动画，不能表述为原始骨骼自动兼容。

志愿军的部分V-Ray材质未直接转译，按部件与UV重新连接12张颜色贴图，并保留灰色织物派生图。两套人物分别校准腕部位置、重整初始姿态并重新蒙皮。保留原始压缩包、MAX、贴图和可编辑适配Blender工程。

初次试接出现袖口与手掌断开，常规身高和骨骼断言未发现该外观问题。已按模型独立校准腕部并补静止、行走、瞄准的袖口接缝检查，再次复查实际游戏截图。首次检查命令还曾误用相对测试路径，已修正为工程内资源路径；该失败不计为游戏功能错误。

## 验收

人物实际渲染专项60/60通过，涵盖4类人物、阵营模型、有效蒙皮、人类比例、接地、袖口、走路、瞄准握点、受伤治疗及倒地。截图在source-characters/，运行日志为character-render.log。

首次整套回归的两条军服检查沿用了旧模型的纯色材质判定，已改为抽样读取实际军服颜色贴图与材质叠色，检查中性灰和明暗细节。第二次运行的历史开场检查又沿用“每个友军均带隐藏日军配件”的共享模型假设，已适配独立阵营模型并逐演员检查实际资产。原失败日志分别保存在source-regression-first-failed.log和source-regression-second-failed.log；S32定向复验27/27通过，修订后完整源码回归22组669项通过。

源码完整回归另完成21点离场采样，正常敌人AI通关击败19人、剩余生命91。1280×720与960×540画面专项各46项通过，覆盖我军红星和正确模型、安全持枪、电报房连续镜头、近战及全屏音量拖动；复看了实际截图。可见近战手臂最大长度约0.755米、握点误差约0.0083米。

新版已构建，独立发布包从源码目录之外运行，同样通过22组669项检查、21点离场采样与19敌AI通关；1280×720和960×540专项各46项通过。发布包人物渲染60/60通过，并复看实际发布包的我军外观与近战画面。源码和发布包均未在本次最终运行中报告脚本或引擎错误。
