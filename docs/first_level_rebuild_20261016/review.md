# 第一关整图重构

本轮对应S10，按用户最新要求保留第一关原剧情和现有模型，整体重建空间布局，并补齐林场生产生活与林缘布景。研究与设计依据见research.md。源码与独立试玩包完整回归、有画面通关、边界与固定机位性能测量均已完成；打包和原件校验汇总见final-validation.json及package-integrity.json。

## 路线与节奏

接头林道 → 检查口 → 运输林道 → 木料场 → 装卸林道 → 电报房 → 北路护送 → 渡口。地图纵深304米，前两道关口间隔76米；补景后导航测得包含室内任务的主路约572.6米，完整试玩仍继续到原松岭屯。

检查口先提供观察和掩体，再组织正面交火；运输林道用折弯和坡体分隔下一场战斗。木料场用原木、箱堆和现有棚屋组织短距离推进；第二次转场后再揭示电报房。取册、断电、救人和两次刺刀互动保留，最后护送陆山沿北路到船边掩护30秒。

实墙和实体土坡承担路线边界及遮挡；0.8米低铁丝网仅封无任务支巷。车辙、路灯、路牌和随拐点改变的目标提示共同表达主路。开场农村广景、林场广景与人物接管镜头迁入新布置，原旁白、录音、字幕及两段时长保持。

## 实现与兼容

- first_level_layout.gd集中维护锚点、主路和旧地图迁移，地图版本为5。
- first_level_world.gd生成新图，从实际碰撞采样室外导航；同时以胶囊扫过网格连接，避免细树干和桶落在两格之间被遗漏。电报房继续使用独立细网格，户外路线避开房内。
- 建筑完整基础范围预留给导航，避免角色在低基础边缘卡脚。土坡网格和其碰撞一同保留，不被静态画面合并释放。
- 四个旧首关阶段从磁盘恢复，核对任务、弹药、关口、位置和剩余掩护时间。第二关原农村布局与脚本继续保留。
- 追兵固定从入口木堆后方进入新渡口通路；实际战斗检查记录首次交火时的剩余掩护时间。
- 按用户追加要求补足可玩区空地，新增棚屋、木垛、生产生活器具、坡脚露岩、林缘野草、近树和外围山脊。8座林场棚屋复用已去英文的派生贴图，原始GLB、下载包和第二关原农村保持。具体布置见scenery-review.md。
