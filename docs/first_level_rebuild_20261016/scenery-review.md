# 林场补景与年代约束

用户要求补足空地，允许使用既有石头、山、树木、房屋和木头等模型，并符合二战东北抗日时期的环境。

## 本轮布置

- 接头林道：林工棚、取暖柴垛、劈柴墩、斧头、木桶、干粮箱和编筐；村边屋顶与伐木棚共同进入到达视野。
- 检查口作业区：既有林场棚屋旁增加卸料垛、长材堆、手工作业台、周转木箱和采伐树墩。
- 木料场：分拣长短材、工具台、装卸用箱筐和取水桶，木屑地表围绕作业点分布。
- 转场林道：路肩露岩、幼松、蕨丛、落叶和疏密不同的松林；运输主路保持空出。
- 电报房及护送路：房侧柴垛、日用箱与储水桶，林缘树石分隔路边空地。
- 外围：不规则起伏山脊承接远林；山体在可玩区、河面和建筑基础周围渐退到地面以下。

使用原有房屋、松树、扫描石块和木制器具；没有新增现代机械、塑料容器、电力路灯、现代招牌或现代道路设施。服装与人物沿原模型保留，不能把本次环境合理性复查写成全面历史考据。

新增固体道具使用模型三角碰撞，成组原木及树干用对应简化碰撞。碰撞随导航初始化采样，轮次验收继续检查全部任务锚点、敌人落点、关口、封路、旧档和实际AI通关。
