# 设计与固定约束

## 世界与路线

1938年深秋，东北抗联背景原创虚构任务。沈砚进入青岚林场取得名册、断电、救出陆山并掩护撤离。两人顺流渡河，姜岚对岸接应，再进入松岭屯救援。天池用于数日前任务序幕及地域意象，不把虚构任务称作真实天池战役。

路线：接头林道、检查口、运输林道、木料场、装卸林道、电报房、北路护送、30秒渡口掩护、双人渡河、密林土路、松岭屯村口/主街/北院。

## 线性关卡

保留首关剧情与模型，通过道路转折、地形、实墙和战斗门控制视线与顺序。实墙遮挡后续敌人，约0.8米铁丝网只封误入支路，不能替代实墙或扩大成高围栏。

以“东北农村”原大型院落为素材，12组院落重新拼成约3.6米窄街，三处敞开院门的穿行段提供转角巷战，三段战斗用实墙院门控制顺序。开场广景结合农村与村边伐木场。房屋、原木、工具、树石和山体按二战东北生产生活用途布置，保留交火、院内转折与战友跟随空间。

## 两段开场

历史序章使用用户完整录音和固定旁白，当前录音约68.18秒；随后以原创战友对话和任务介绍引入战斗。参考剧情类FPS的关系铺陈和危机推进节奏，不复制其人物台词。艺术化天池突出火山口湖、环形山壁及交谈岩台，不要求1:1复刻。

固定历史旁白全文：

> 作为中国共产党创建最早、坚持抗日时间最长、条件最为艰苦的抗日武装力量，东北抗日联军在民族危亡之际，高擎抗日救国大旗，在白山黑水间、在冰天雪地里、在茫茫林海中，孤悬敌后，进行了艰苦卓绝的斗争。忠诚于党的坚定信念、勇赴国难的民族大义、血战到底的英雄气概，这是战火磨练铸成的东北抗联精神，也是中华民族在每次危难之际迸发的复兴强音

保留用户录音、第一人称手臂、现有98k及人物成果。无录音对白只用字幕。A10扶人方案已取消，当前为电报房背枪行走与滑动镜头。
