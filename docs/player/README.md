# 烽火回声 · 林海归途

**Windows 64位离线单人剧情射击游戏 | 0.7.2-rc1 试玩候选版 | 2026年10月18日发行整理**

1938年深秋，一份落入敌手的名册，一名等待救援的交通员，一条穿过林场、河流与村庄的归途。你将扮演抗联战士沈砚，在战友接应下深入青岚林场，夺回情报，掩护伤员撤离，再穿过松岭屯，为队伍打通出路。

本作以东北抗日联军的历史背景为基础，讲述原创的虚构任务。青岚林场、松岭屯及本次行动为创作设定；开场天池为服务人物与叙事的艺术化火山口湖，不对应一场真实的天池战役。

## 故事与人物

在白山黑水间，情报与交通线维系着队伍的生存。敌人控制了林场及周边道路，一份关系到同志安危的名册必须及时夺回。沈砚带着任务进入林海，与侦察员姜岚接头，寻找被困的交通员陆山。

| 人物 | 与你的关系 |
|---|---|
| 沈砚 | 玩家扮演的抗联战士，负责夺取情报、救人与突围 |
| 姜岚 | 侦察与联络战友，提供任务线索，在村庄接应并协同作战 |
| 陆山 | 需要营救和护送的受伤交通员，撤离时与你共同渡河 |
| 林守义 | 林场中的接应者，可提供一次物资补给 |

历史序章保留完整旁白，随后通过战友对话进入原创任务。已有角色录音与字幕共同叙事，部分新增对白目前仅有字幕。

## 游玩流程

当前版本包含相互衔接的林场与村庄两段关卡，以及中间的渡河和密林行进。路线按剧情顺序展开，沿道路、土路、院门和任务提示前进。

1. **接头与进入林场。** 沿林道找到姜岚，了解任务。穿过检查口、运输林道与木料场，利用原木、墙体和地形交替推进。
2. **进入电报房。** 清理沿途敌人，寻找名册及相关线索，切断电源，接应陆山。近身遭遇中出现反制提示时，连续松开再按空格。
3. **护送与守住渡口。** 陪同陆山撤离，注意跟随和等候状态。抵达渡口后掩护解缆30秒；离开掩护区域、暂停或让陆山等候会暂停倒计时。完成后按提示交谈、登船。
4. **顺流渡河。** 两人乘船离开渡口，顺河漂流靠岸。上岸后沿与林地颜色不同的土路穿过密林，听取姜岚的村口介绍。
5. **松岭屯穿院战斗。** 从村口西院进入，经东侧夹巷推进至北院。三段战斗依次开放院门，利用院墙、门口和转角掩护，完成最后会合。

遇到暂时关闭的任务门，先清理当前区域并确认任务目标，再靠近按F互动。找不到目标时按J查看行动记录。林守义的补给只能领取一次；前两处任务栅门旁在两种枪都无弹时可领取应急步枪弹。

## 值得体验的地方

- **一条有起伏的归途。** 接头、突入、搜寻、护送、守点、渡河和穿院突围连成完整任务。安静的行进与短促交火交替出现，战友关系贯穿行动。
- **用环境组织路线。** 林场的折弯山谷、实墙和生产设施遮挡后续战斗；低铁丝网封住误入支路。上岸后的土路引导穿林，村内则用窄街和相通院落展开转角交火。
- **东北村落与林场的生活感。** 原东北农村建筑组成12组大院，搭配土路、木料、柴垛、树木与山石，将生产空间、生活院落和战斗掩体结合起来。
- **有过程的枪械操作。** 98k栓动步枪与手枪提供不同节奏；第一人称手部表现托枪、瞄准、拉栓和装填，步枪按实际缺弹数将子弹压入机匣。
- **与战友共同撤离。** 任务中有交谈、补给、伤员护送、等候指令和友军火力支援。乘船过河后，故事继续进入村庄。
- **可调节的第一人称体验。** 支持蹲伏、探头、跑步镜头起伏，提供三档画质、音量分类和镜头晃动调节；可离线游玩并从检查点继续。

## 设置、存档与卸载

标题页和暂停菜单可调整性能/均衡/画质三档、限帧、垂直同步、全屏、鼠标灵敏度及各类音量。默认使用均衡画质；遇到不流畅可先选性能档。对镜头晃动敏感，可把“镜头与武器晃动”调为0。

存档与设置保存在 `%APPDATA%\FenghuoEcho\`，与安装文件分开：

- `qinglan_checkpoint_v2.json`：任务检查点。
- `presentation_v1.cfg`：画面、声音和操作设置。

游戏按任务检查点记录进度，并非任意时刻手动存档。开始新游戏会替换已有检查点。开场中断从当前演出段开头继续，过河中断从登船前的安全点继续，上岸及林中检查点保留行程。

安装版与免安装版使用同一用户存档。卸载安装版或删除免安装文件夹会保留上述存档；需要彻底重置时，在退出游戏后自行处理该用户目录。请勿同时运行两个游戏实例。

## 当前版本说明

这是持续制作中的试玩候选版。0.7.2系列已加入树林分块、院落合批、三档画质和物理优化，修订入村山体、渡口表面、托枪和压弹；本次交付同时包含最新入村路面接缝修复与跑步镜头晃动。

部分对白尚未配音，连续人物表演、美术观感、真人难度与其他硬件表现仍需反馈。此前渡口附近出现过一次明显短暂停顿，尚未确认消除。不能据单机测试承诺所有电脑上的帧率或最低配置。详细限制见 `KNOWN_ISSUES.md`。

如遇异常，可在[项目问题页](https://github.com/zhaichaofan3/DongBeiKangLian/issues)提供版本、所在任务、复现步骤、画质设置及电脑配置；附上截图或日志有助于定位。
