# 0.7.2-rc1 试玩说明与已知限制

发行整理日期：2026-10-18。游戏内容与2026-10-17通过专项验证的0.7.2-rc1运行包一致；本次主要增加安装、分发和玩家文档。安装/压缩包检查不等同于重新完成全部游戏回归。

- 首次启动需要装配两关场景并准备导航，开始/继续按钮会在准备完成后开放。加载时间取决于电脑性能。
- 此前渡口附近记录过一次约635毫秒的长帧，尚未定位或确认消除。不同硬件的流畅度、最低配置和长时间连续游玩仍待验证。
- 渡河交接时仍可能出现引擎相机插值警告。已验收的专项运行可正常结束，但连续表演观感仍需真人反馈。
- 新增渡河、入村及部分任务对白只显示字幕，暂无完整角色配音。混音、声音衔接与连续听感仍待人工验收。
- 连续人物动作、整体美术与地形融合、真人难度和跑步晃动舒适度尚未最终验收。可在设置中把“镜头与武器晃动”调为0。
- 存档以检查点恢复；开场恢复当前段开头，渡河中断恢复登船前，上岸/林中检查点保留进度。开始新游戏会替换当前检查点。
- 当前发行面向Windows x64与键盘鼠标，其他平台和手柄未验收。安装程序未作代码签名，可能出现未知发布者提示。

游戏内容专项的原始摘要随包保留为 `release_validation.json`。本次安装与归档验证另见仓库 `docs/distribution_20261018/`，两者分别记录。
