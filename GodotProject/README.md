# 东北抗联-烽火回声

本地试玩候选版0.7.2-rc1，2026-10-16性能与画质修订。故事发生在1938年深秋的虚构青岚林场与松岭屯。Godot 4.7.2 / GL Compatibility，Windows可离线运行。

## 启动

试玩包解压后双击 `FenghuoEcho.exe`，保留同目录PCK、许可和来源说明。源码从根目录 `Start-Game.cmd` 运行，或使用 `Start-Game.ps1 -Editor` 编辑。首次克隆需要Git LFS和Godot，安装方法见仓库根README。

“开始游戏”播放历史序章和战友任务引入；“直接进入林场”从接头开始。Esc暂停，Enter跳过当前演出。已有村庄旧档会迁移到同一战斗阶段的安全位置，保留物资和击杀。

## 当前修订

- 树林按空间分块，重复大院合批，减少视野外场景的绘制；保留原树木数量、路线与碰撞。
- 改进自然光、阴影、地面细节和斜视角贴图清晰度。性能、均衡、画质三档分别使用关闭/2倍/4倍抗锯齿，原生分辨率保持不变，默认均衡。
- 首次打开需准备两关场景，开始与读档按钮在准备完成后开放。较低配置可选性能档，并按屏幕刷新率设置限帧或垂直同步。
- 处理上岸首次接地的明显停顿；入村山岭避开整条土路，路面转弯连续，渡口河岸和栈桥错开重叠表面。
- 左手贴近护木托枪；装填按实际缺弹数显示一至五发子弹，拇指压入后退出空夹并推栓闭锁，保留原手部模型与录音。
- 村庄使用原东北农村的12组大型院落重新拼接，两侧房屋和院墙靠近，街道约3.6米宽。三处穿院路线绕过封街木料，在院门、窄巷和构筑物转角交火；原三段战斗和清敌后开门规则保留。
- C切换蹲下，Ctrl按住蹲下，Q/E按住左右探头。墙边限制头部位移，冲刺和暂停收回探头；互动改F，包扎改H。
- 电报房补实体外墙并保留既有入口；渡口临水地面与遮挡调整，河水可见。渡河航线改为与水流一致的下游，避开码头。
- 历史开场加入电报设备特写，保留用户完整旁白和原总时长。村内补松树、石块、柴垛等，并使用灰褐土路。

用户第一人称手臂、98k、原录音和首关剧情保留。旧制作过程见仓库 `docs/PROJECT_HISTORY.md`，最新验收见 `PROGRESS.md`。

## 路线

**接头林道 → 检查口 → 运输林道 → 木料场 → 装卸林道 → 电报房 → 北路护送 → 渡口掩护 → 双人顺流渡河 → 密林土路 → 村口西院 → 东侧夹巷 → 北院。**

林场共13名固定敌人。清理前两区后按F开门，第二门后有刺刀突袭。电报房最后一名守卫近身争枪，连续按空格反制。拿名册、拉总闸、接应陆山后前往渡口，掩护解缆30秒；追兵每组2人，当前组清空后1秒补入下一组。离开渡口、暂停或让陆山等候时倒计时暂停。

解缆完成后按F交谈并登船，与陆山顺流过河。上岸沿土路穿过密林，听完姜岚的村口介绍后进入战斗。姜岚跟随并提供火力，陆山留在岸边保管名册。村庄每段4名敌人，清完本段后按F打开院门；全部12人肃清后在北院会合。

林守义提供一次补给。两种枪都无弹药时，前两处任务栅门旁可按F取应急步枪弹。

## 设置与存档

标题页或暂停菜单可调整画质、帧率、垂直同步、全屏、灵敏度、武器晃动及五类音量。音量即时保存，0%静音。历史段旁白与自带配乐统一受剧情动画音量控制。

设置和检查点位于 `%APPDATA%\FenghuoEcho\`，文件为 `presentation_v1.cfg` 和 `qinglan_checkpoint_v2.json`。新游戏替换检查点。开场中断从当前段开头恢复，过河中断从登船前恢复，上岸和林中检查点保留行程。测试使用独立QA文件。

## 内容与限制

历史段保留用户68.18秒完整录音和17条字幕；任务段已接入8句录音，其他对白保留字幕。两段共28镜，约148秒。渡河和入村新增对白暂未配音，不用临时合成语音代替。

真人难度、连续人物表演、雪地与坡道美术融合、声音听审及其他硬件表现仍待验收。自动检查和截图不代替真人体验，见 `KNOWN_ISSUES.md`、`VERIFICATION.md`。

资源来源及使用条件见 `ASSET_SOURCES.md`、`AUDIO_CREDITS.md`、`AssetNotices/`。项目混合多种许可，不具有统一MIT或CC0授权。
