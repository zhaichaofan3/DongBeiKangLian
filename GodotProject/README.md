# 东北抗联-烽火回声

0.7.0-rc1 本地试玩候选版，2026-10-16双人渡河与密林入村修订。东北抗联题材原创单机第一人称游戏，故事发生在1938年深秋的虚构青岚林场。引擎为Godot 4.7.2 / GL Compatibility，可离线运行。

## 启动

试玩包解压后双击FenghuoEcho.exe，保留同目录PCK、许可和来源说明。源码位于仓库GodotProject目录；开发者先安装Git LFS与Godot，再用根目录Start-Game.cmd运行，或Start-Game.ps1 -Editor编辑。安装与环境设置见仓库根README。

选择“开始游戏”观看两段开场，Esc暂停，Enter跳过当前段。选择“直接进入林场”则先与姜岚交谈。林场13名固定敌人，渡口有追兵，过河后另有12名村庄敌人。体验完整布置请开始新游戏；旧渡口完成档可继续登船。

- 上岸后先走一段可玩的密林土路，约2000棵实例松树围合路外区域，土路颜色与林地明显不同。沿路到原村口触发姜岚短对话，之后才开启村庄战斗；原22组院落、三段战斗和任务门保持。

## 路线

**接头林道 → 检查口 → 运输林道 → 木料场 → 装卸林道 → 电报房 → 北路护送 → 渡口 → 双人顺流渡河 → 密林土路 → 松岭屯村口 → 主街 → 北院。**

检查口3名、木料巷4名、电报房4名守卫，另有第二门突袭兵与渡口守卫，共13名固定敌人。清理前两区再按E开门，第二门后有刺刀突袭。电报房最后幸存者沿畅通直线冲锋，接近后进入争枪，连续按空格反制。

拿名册、拉总闸、接应陆山后，绕房子北侧前往渡口。到船边掩护解缆30秒，左上角显示剩余时间。追兵每组2人，清除当前组后1秒补下一组；解缆结束停止补兵。离开渡口、暂停或命令陆山等候时，倒计时暂停并保留进度。完成后按E交谈并登船，与陆山顺流过河。下船后沿土路穿过密林，到村口听完姜岚的情况介绍后进村。

姜岚跟随并提供火力支援，陆山在船边保管名册。村庄每段4名敌人，清完本段后按E打开院门；12名全部肃清后，在北侧会合点按E完成任务。过河补充弹药、绷带和部分生命，院门进度、存活敌人及战友位置进入检查点。

可向木棚里的林守义领取一次补给。两种枪都无弹药时，在前两处栅门的应急补给点按E取5发步枪弹，再按1、R装填。

## 设置与检查点

标题页或暂停菜单可调整三档画质、帧率、垂直同步、全屏、灵敏度、武器晃动及五个音量。音量即时生效、显示百分比、自动保存，0%为静音。

| 音量 | 范围 |
|---|---|
| 总音量 | 全部声音 |
| 背景音量 | 全局配乐，默认22% |
| 音效音量 | 枪声、拉栓、脚步、流水、爆炸、门声 |
| 对话音量 | 人物对白、警戒和冲锋叫喊 |
| 剧情动画音量 | 两段开场整体 |

历史段为用户完整录音，旁白与自带配乐一起由剧情动画音量控制，全局音乐暂时停播。任务序幕各层同时受其分类与剧情动画音量控制；暂停后调音量不会打断原播放位置。

设置与存档在%APPDATA%\FenghuoEcho\，分别为presentation_v1.cfg和qinglan_checkpoint_v2.json。任务、物资、人物、敌人、栅门和撤离进度自动记录。新游戏会替换当前检查点。开场中断按A段或B段开头恢复；过河中断从登船前恢复，上岸和林中检查点保留行程。刺刀未完成时恢复突袭前的安全检查点，旧档不强制重演已完成互动。测试使用独立QA文件。

## 内容与限制

历史段使用用户68.18秒完整录音和17条字幕，包含建筑滑动长镜头；任务序幕已接入姜岚8句用户录音，另6句保留字幕、暂不发音。两段共27镜，约148秒。已接入艺术化长白山天池、山坡树林、原有建筑布景、枪火、炮弹、用户音乐与11项音效。

新人物使用两套用户模型和现有13骨程序动作；我军使用用户人物自带手套，日军接触手沿用现有成果，玩家第一人称手臂未改。陆山旧额头绷带已取消，保留腿部包扎。雪地、坡道融合、连续表演观感、声音听审、混音与完整真人难度仍待验收。自动检查和截图不代替真人体验。原A10扶人已取消，不再作为待补项。详见KNOWN_ISSUES.md及VERIFICATION.md。

原对话录音清单在Dialogue/dialogue-recording-list.txt，共32条对白，8条已配音、24条保留字幕待补录，另有4条可选答句。本轮另增6段渡河与入村字幕，见Dialogue/river-journey-subtitles.md，暂未配音。未提供录音的对白不播放临时合成语音。资源作者、许可和加工信息见ASSET_SOURCES.md、AUDIO_CREDITS.md与AssetNotices/，引擎许可随包提供。

## 开发入口

源码与发布包分别测试，发布复测从源码目录外启动exe/PCK。根Test-Game.ps1运行统一回归，-Release验证发布包；tools/Verify-PolishRevision.ps1进行两种尺寸的画面与全屏拖动检查，支持-Release。根Build-Game.ps1先导出临时PCK，成功后替换正式包。

开发说明见仓库根README和docs/DEVELOPMENT.md，当前状态见PROGRESS.md。可编辑人物、手部、建筑、天池及原录音在AssetLibrary；后续使用Git/LFS记录版本。2026-10-16已精简旧重复截图与转储，历史Validation引用仅表示当时记录，当前分发包不包含这些实验输出。
